# Evidence and Reimbursement

One plugin. Upload it in Cowork, then connect the Digital Health Library on this plugin's Connectors tab and provide the bearer key there. The key is not in this pack.

The pack opens on three cores and one expert download. A core lists its jobs. A job loads one task. A task calls https://mcp.vital.expert/api/mcp/library only when the task names a tool. Finding an expert is free. Downloading one expert is one counted call on that same key.
