# Methods changes that can date an existing model (A2)

Interpretive reference for A2. Each change carries its date, the instrument that made it, and its row. All read 19 October 2026, not owner-reviewed. A change matters to the person only if their model or evidence was built before it and the body applies it to their topic; say which, from the person's dates.

## How to use this in A2

1. Take the person's model date, topic dates and target bodies.
2. List the changes after the model date that the body applies to the topic.
3. For each, say what in the model it touches (value set, threshold cited, BIA framing, reporting checklist), as a fact; whether to update is the owner's decision.
4. Check the studies the model rests on with `verify.check_currency` (retraction, correction, supersession).
