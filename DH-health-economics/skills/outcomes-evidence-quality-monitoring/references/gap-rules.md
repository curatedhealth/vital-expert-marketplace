# Gap rules

A gap is information. Say why something is missing, because each reason leads to a different next step.

| Situation | How to word it | Next step |
|---|---|---|
| The paper does not report a fact a domain needs | "Not reported in the paper `[GAP]`" with the domain | Ask the authors or the study team; reviewers may answer "No information" (ES-72, ES-76) |
| Full text not available, abstract only | Open-access source: read the full text first; `[GAP]` only if the full text also lacks it. No full text: "Abstract only: domain facts not checkable `[GAP]`" | Get the full text before any judgment |
| Library label disagrees with the paper | "Library label X; the paper's methods describe Y" | Use the paper |
| No registration link from the library | "No ClinicalTrials.gov link found by the library; registration not confirmed `[GAP]`" | Ask for the registry record |
| A rule the sources do not fix (ROBINS-I overall below critical, STROBE item wording) | "Not in the sourced rows `[GAP]`: your rule" | The person sets it |
| A reviewer judgment is missing | "Domain not judged `[GAP]`" | Overall and score not computed |
| No evidence rule set | "No rule set: factual summary only" | No verdict |
| The person has not named an owner | "Owner not named" | Ask; never assign |

## Never

- Never turn a missing fact into a judgment of bias, or "no registration found" into "unregistered".
- Never fill a domain judgment, a point value or a weight the reviewers did not give.
- Never present a draft GRADE level from the library as the certainty of the evidence.
