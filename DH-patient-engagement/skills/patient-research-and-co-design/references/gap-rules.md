# Gap rules

A gap is information. Each reason for a gap leads to a different next step, so name the reason.

## Requirement and method facts

| Class | When | How to word it | Next step |
|---|---|---|---|
| Sourced | A research row states it. | The fact plus the row id (for example "PPI guidance final 30 March 2026, PE-22"). | None. |
| Code, not law | The row is marked [INDUSTRY]. | "[INDUSTRY] EFPIA Code, not law (PE-77)." | The person's compliance owner decides whether the code binds them. |
| Method paper | The row is marked [PAPER]. | Cite the DOI; say it is a published method. | None. |
| Read by a summarizer | The row is marked [WF]. | "Read through a fetch tool, not checked verbatim." | Check the page before relying on it outside the conversation. |
| Register rule | An R row from the earlier skill. | "Register starting rule R-10, yours to adopt." | Ask whether the person adopts it. |
| Draft or superseded | A row says draft (PFDD Guidance 4, PE-17) or superseded (2016 PPI guidance, PE-22). | "Draft, for comment only (PE-17)." | Do not plan on it as final. |
| Not in the sources | The question needs a fact no row holds (Common Rule consent elements, GDPR for recordings, UK ethics approval routes, NICE patient expert submissions, a co-design sample size). | "Not in this skill's sources `[GAP]`." | Ask the person's ethics, privacy or regulatory owner. |

## The person's facts

| Situation | How to word it |
|---|---|
| No decision named for the research | Ask. Without it the question cannot be written (R-1). |
| No participant type stated | Ask: patients, carers, or both, and why (R-2). |
| No owner named for a decision | Use the owner or role the person names, in their words. Only if they named none, write "owner not named" and ask. Never suggest a job title. |
| No rule for a repeated point | Show the counts with no "repeated" label; offer R-10 as the starting rule. |
| No scores for B1 ranking | No ranking. Lay out the facts per point and ask the person to score. |
| Words paraphrased in the notes | Mark the capture "paraphrased by the note-taker" and keep it apart from verbatim words. |
| Identifiers in a file | Stop; ask the person to remove them and send the file again. |

## Library facts

| Situation | How to word it |
|---|---|
| No co-design study found for the condition | "No co-design study for this condition in the sources searched (Cochrane, Embase and Scopus are not loaded); absence is not evidence that none exists." |
| Design label conflicts with the title | Report the title's design; note the library label. |
| Verify returns "partial" | Treat as unverified; do not use the claim. |
| Guidance passage without a source URL | Do not use it. |

## Never

- Never fill a requirement, a consent element, an exemption, an owner, a score or a decision from memory.
- Never treat a missing row as "not required" or "allowed".
