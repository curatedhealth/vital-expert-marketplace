# Gap rules

A gap is information. Each reason for a gap leads to a different next step, so name the reason.

## Method facts

| Class | When | How to word it | Next step |
|---|---|---|---|
| Sourced | A research row states it. | The rule plus the row id (for example "ICC at least 0.70 for sufficient reliability, COSMIN, PE-95"). | None. |
| Draft guidance | The row is a draft (PFDD Guidance 4, PE-17, PE-19, PE-20). | "Draft guidance, distributed for comment only (PE-17)." | Do not present as an FDA requirement. |
| Abstract only | The row was read from an abstract (PAM-13 2005, Yardley 2016). | Say "abstract only" once. | Read the full text before relying on detail. |
| Licensed or not public | PAM level cut points and scoring; GAD-7 cut points. | "Not in this skill's sources `[GAP]`; PAM scoring is licensed." | The person's license holder or instrument documentation. |
| No sourced tolerance | An acceptable difference between dashboard and recomputation, or an acceptable missing-data share. | "No sourced tolerance `[GAP]`; the rule is yours." | The person sets it. |

## The person's facts

| Situation | How to word it |
|---|---|
| No card for a dashboard KPI | "No card, no agreed definition"; the KPI is not recomputed as agreed. Recompute the dashboard's own definition if it is available, labeled as such. |
| No dashboard definition | "Dashboard formula not seen"; drift cannot be checked; only the value is compared. |
| No dashboard value or refresh time | Recomputation is reported alone; ask for the number and its refresh time. |
| No acceptable difference set | Report the difference; no verdict. |
| No instrument evidence named | "Measurement evidence not named"; list the COSMIN properties to look for; no rating. |
| No owner named | Use the owner or role the person names, in their words. Only if they named none, write "owner not named" and ask. Never suggest a job title. |
| No refresh named for a repair | Leave it blank and ask; never pick a date. |
| No scores for B1 | No ranking. Lay out the facts per repair and ask the person to score. |

## Data problems

| Situation | How to word it |
|---|---|
| Blank or invalid dates, duplicates, events after the as-of date | Count them; exclude them; never impute. |
| Events before a person's start, or no start event | Count; exclude; ask whether the start event is right. |
| A month with no events | "No events recorded in MONTH: a feed outage or a real stop cannot be told apart from this file." |

## Library facts

| Situation | How to word it |
|---|---|
| Verify unreachable | "Verify was not reached; cited from the reference row." |
| Literature search returns nothing relevant | "No record found by this search; absence is not evidence that no paper exists." |

## Never

- Never fill a definition, tolerance, threshold, owner or rating from memory.
- Never impute missing data or adjust a number to match.
- Never treat a KPI with no data as zero, or a missing card as agreement.
