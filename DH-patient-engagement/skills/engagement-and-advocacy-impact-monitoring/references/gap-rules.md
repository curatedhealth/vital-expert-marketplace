# Gap rules

A gap is information. Name its reason.

## Method facts

| Class | When | How to word it | Next step |
|---|---|---|---|
| Sourced | A research row states it | The fact plus the row id ("report dropout and nonusage attrition separately, PE-102") | None |
| Abstract only | The row quotes an abstract (PE-100, PE-104) | "From the abstract only (PE-104)" | Read the full text before relying on detail |
| Not sourced | A cut point or benchmark the rows do not hold (PAM levels, an engagement norm) | "Not in this skill's sources `[GAP]`" | The person sets the rule |
| Industry code | An [INDUSTRY] row | "ABPI Code [INDUSTRY], self-regulation, not law (PE-82)" | Ask whether the company is bound |
| Yearly figure | The safe-harbor cap | "$623 for calendar year 2026 (CP-US-27)" | Read OIG's figure for another year |

## The person's data

| Situation | How to word it |
|---|---|
| No record for an activity | "Unscored (no record)"; never zero |
| No target or pass rule | Show the number; write "no rule set, no verdict"; ask for the rule once |
| No denominator (reached) | Give the count only; say the share cannot be computed |
| No as-of date for attrition | Ask; ages and curves need one |
| No owner named | Use the owner or role the person names, in their words. Only if they named none, write "owner not named" and ask. Never suggest a job title. |
| No scores for B1 changes | No ranking; lay out the results and options and ask the person to score |
| Patient-level data offered | Ask for pseudonymous ids or aggregates; never put patient data in a library call |

## Library facts

| Situation | How to word it |
|---|---|
| `analytics.rice` given confidence as a fraction | Rerun with percent; report only the percent run |
| Library returned 502 or 503 twice | "The library did not answer; nothing was counted" |
| No literature found | "No paper found for this query; absence is not evidence that none exists" |

## Never

- Never fill a result, target, score, owner or date from memory or by estimate.
- Never treat a published rate or a population figure as a target.
- Never call program engagement clinical evidence.
