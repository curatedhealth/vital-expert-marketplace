# Finding card

Number findings 1…N in workstream order. One card per material finding.

```text
### Finding N — {workstream}:{id}
Claim: …
Support: rule / VP / primary URL / [CHECK] / [GAP]
Severity (deal lead): open | watch | closed
Blocks: …
Not: FTO opinion | AI recommend-sign | ASC/FC enable | Marketplace Done
```

Machine path (optional): `tools/stamp_check_line.py --extra "Finding N"`.
