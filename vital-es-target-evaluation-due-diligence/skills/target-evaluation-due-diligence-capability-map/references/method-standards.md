## Judgement rules
- Assembler never recommends GO/NO-GO / proceed / walk; sign-off stays HUMAN ONLY (anti-pattern: practitioner blogs that open with proceed/walk — staged, not absorbed as templates).
- Pack should retain significant contrary findings alongside conclusions (CM2 analog).
- Optional COI / independence-in-appearance **disclosure** on integrated report §7 (CM3, CM8, CM9, CM10); ICAEW conflict-at-outset pattern (CM6). Disclose or state human-declared “none disclosed”; **do not invent clearances**. Undisclosed significant conflict → stop participation (CM10 / VP-CM-093).
- Optional AI-use disclosure when the pack itself used AI drafting (CM4).
- Scope-and-limits section preferred over MD&A / safe-harbor boilerplate (CM6, CM7).
- Never claim Standard Pass from eng smoke alone.
- IESBA / ISACA ITAF / PSLRA / AS 1220 remain PARTIAL until free primary dual-read reopen (ISACA skipped this pass — not confirmed free HTML).
