# Gap rules — capability map / integrated diligence

A gap is a fact the pack needs that nobody has supplied or no admitted source states. Write `[GAP]` (or keep `[CHECK]` for dual-read-pending) with the reason and what would close it. Never fill from general knowledge; never let a gap become a silent assumption.

| Kind | Example | How to word it |
|---|---|---|
| Missing workstream output | No C register for exclusivity | `[GAP] Skill C register missing; IR cannot roll exclusivity.` |
| Claim without source/rule | "Strong IP" with no family list | `[GAP] No patent family / exclusivity posting cited.` |
| Human-only opinion asked of AI | "Are we clear to operate?" | Refuse — counsel FTO; do not invent clearance. |
| Deferred enable presented as Done | "ASC model enabled" | Keep Accepted Deferred; do not enable. |
| Connector empty | Orange Book fetch failed | `[GAP] Listing not retrieved; do not invent exclusivity end date.` |
| Cross-stream conflict unreconciled | B launch vs C exclusivity | Show both sides (R-CONF-*); never pick a winner in IR. |
| COI / independence | "Cleared of conflicts" | Disclosure only — never invent clearance. |

## Rules

- Missing skill output → GAP for that workstream + REQUIRES route — not a fabricated green status.
- Wide uncertainty ranges are honest; baseless point estimates are gaps.
- Accepted Deferred (ASC / FC-* / Full / Marketplace) are owner HITL, not content gaps to invent closed.
- In IR §5 list gaps most blocking first; in a short answer at most three.
