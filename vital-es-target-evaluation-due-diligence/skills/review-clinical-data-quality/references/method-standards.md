# Method standards (what the register is judged against)

**Status rule (upgrade lane, 7 November 2026).** VERIFIED-REOPENED = the primary or official text was opened in the build, the wording appears in it, and the passage is registered in `verbatim-passages.json` (exact text, section, page, URL, access date); the passage ids are in the "Passage ids" column and a row without a registered passage cannot carry this status. SUMMARY-ONLY = abstract, summary page, preview or secondary report only; never used for a figure, rule or quoted wording. [CHECK] = not verified, with the reason; never scored. Pages in the register are PDF page indices of the file opened. Reading standard for Draft: fetched page text is acceptable; exact wording must be re-checked against the official text before Released.

No published standard prescribes the structure of a clinical data quality register for a licensing or acquisition diligence, or the order of its steps. The skill therefore applies published methods to each judgement (risk of bias, estimand, surrogate precedent, regulatory routes) and labels its own design choices ENGINEERING RULE with a reason in `grounding-register.md`.

## Judgement rules
- Name the standard in the row (for example "RoB 2 randomisation domain: some concerns, FICTIONAL p. 14").
- RoB 2 is judged per result and per effect of interest; the register row names both. CONSORT 2010 E&E (M21) grades reporting completeness only — never substitute CONSORT for RoB 2 (VP-A-172).
- Estimand: four attributes plus a strategy for each intercurrent event.
- US precedent is stated from the FDA table (M5) or a regulatory review document, not from memory of a prior approval.
- EU precedent: say "no EU surrogate table exists" (M12, [CHECK]) and cite a qualification opinion only if found.
- Single-arm or externally controlled result: state `sat_prespecified` and `effect_isolation`, and carry the flag EXTERNAL_CONTROL_CAUTION; never replicate-label it (M15 to M17).
- Nothing about a market other than US or EU. [GAP].
