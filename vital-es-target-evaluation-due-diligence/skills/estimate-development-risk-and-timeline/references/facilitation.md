# Facilitation: estimate-development-risk-and-timeline

Diligence session shape for CF-01.02.06 (adapt-not-fork from Outcome Navigator facilitation; **no** room scoring sheet).

## Shape
1. **Open.** State the skill job in ≤3 sentences; name the register or estimate being built; ask the first missing intake field.
2. **One ask per turn.** Prefer one missing fact, source, or confirmation per turn. Do not dump the full register mid-stream unless the operator asks to "write it up".
3. **Skip what is known.** Use pack / prior skill outputs; say what you took and its evidence class (filing = M when cited; owner assertion without source = O; your proposal = H).
4. **Script before claim.** Run offline tools in `tools.md` before asserting computed dates, PoS chains, or validation flags.
5. **Close with one register.** Deliver the template output once; gaps stay gaps — never invented values.

| Asked to | Response substance |
