## Judgement rules
- Every date names its rule id and the passage it rests on; conventions (whole days, calendar months, testing half rounded down) are marked CONVENTION.
- The all-patents date and the composition-only date are both shown; a person chooses which patents count.
- Pediatric six months: attaches to the periods named in S3 (small molecules) and S4 (biologics, rule US-BIO-PED) only when the user states that pediatric exclusivity was granted; for patents only where the user marks pediatric_extends.
- GAIN: applies only to a qualified infectious disease product (user input qidp) that is not a section 262(a) biologic (S5).
- Reform text (S12, S20) is flagged, never applied.
- No freedom-to-operate statement, no validity or infringement judgement (S13: that is a legal opinion).
- Orange Book / Purple Book rows are **listings and exclusivity postings**, not proof a patent is valid or that the asset is clear to operate (S22). Disputes use the FDA Patent Listing Dispute List process; status is a fact for the register, not an AI validity call.
