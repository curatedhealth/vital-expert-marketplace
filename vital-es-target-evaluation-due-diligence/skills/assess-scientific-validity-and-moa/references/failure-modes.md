# Failure modes for the mechanism register

Every register is screened against every mode. Status as in method-standards.md; a VERIFIED-REOPENED row names the registered passages it rests on. The detection questions are written for this skill and are labeled ENGINEERING RULE in grounding-register.md; the finding is the sourced part. Where a cited analysis is by industry-affiliated authors the row says so.

| Id | Mode | Detection question | Documented for | Source and finding | Passage ids | Status |
|---|---|---|---|---|---|---|
| FM-01 | Irreproducible preclinical science | Has each key preclinical finding been repeated by a different organization, and with what result? Does the seller rely on one originating group? | oncology preclinical papers (selected sets); preclinical research in general (estimate) | Begley and Ellis 2012 (industry authors): "scientific findings were confirmed in only 6 (11%) cases" among 53 landmark papers. Errington et al. 2021: 158 effects from 50 experiments in 23 papers; replication effect sizes 85% smaller (median) for positive effects; success rate "46% (51/112)". Freedman et al. 2015: "cumulative (total) prevalence of irreproducible preclinical research exceeds 50%". Selected sets or an estimate; no rate for a given area | VP-F-030 to VP-F-032, VP-F-040 to VP-F-043, VP-F-061, VP-F-100, VP-F-101 | VERIFIED (re-opened) |
| FM-02 | Poor animal-to-human translation | Does the animal model represent the disease features that the drug acts on? ## Notes
- FM-01: a repetition counts as a replication only if it collected its own data (VP-F-100) and the degree of agreement is reported, not a pass/fail (VP-F-101); the different-organization requirement is the plugin's ENGINEERING RULE.
- FM-03: a class-wide warning is regulatory extrapolation from shared mechanism; it supports vigilance and does not prove identical toxicity across compounds (VP-F-121, VP-F-123, narrative review). The FDA draft on labeling changes across several applications (VP-F-130, VP-F-131) does not use the word "class".
- FM-04: genetic-support figures are population-level context; the effect varies with the source type and the confidence in the causal gene (VP-F-003, VP-F-140, VP-F-141) and the GWAS estimate was sensitive to the similarity cutoff (VP-F-151); the GOT-IT recommendations name missing target-disease causal evidence as a major reason for efficacy failure (VP-F-162).
- FM-05: ask what n counts (experimental unit) so that pseudoreplication is not hidden behind a large n (VP-F-110, VP-F-111).
- FM-03 names real products because the FDA page is the source; the names are listed in the local key file (BACKTEST_CASE_KEY.md, held-out exclusion list).
- Add a failure mode only with a source opened in the build; a mode without a published analysis would carry the detection question alone and say so.
