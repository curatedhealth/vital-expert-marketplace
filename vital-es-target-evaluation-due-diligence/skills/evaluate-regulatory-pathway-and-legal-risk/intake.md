# Intake

Ask for every missing item in one message. Do not start on assumptions.

| # | Input | If missing |
|---|---|---|
| 1 | The three upstream outputs, with the reviewer and date: the signed clinical evidence register (review-clinical-data-quality), the probability and timeline ranges (estimate-development-risk-and-timeline), and the exclusivity register (assess-ip-portfolio-and-freedom-to-operate). If any is absent: stop and route to that skill. | ask in the one message; do not start on an assumption; record a [GAP] if it cannot be supplied |
| 2 | Buyer mode (bd or investor), unit (asset, or company with the list of pipeline assets; one run per asset, then a roll-up), and markets in scope (US, EU, or both). Another market is a [GAP]. | ask in the one message; do not start on an assumption; record a [GAP] if it cannot be supplied |
| 3 | The indication, the stage reached, and the designations held or applied for in each market (fast track, breakthrough, priority review, orphan, PRIME, accelerated assessment, paediatric plan). | ask in the one message; do not start on an assumption; record a [GAP] if it cannot be supplied |
| 4 | Regulator correspondence: meeting minutes, scientific advice, any complete response letter or refusal, any agreed confirmatory-trial plan. | ask in the one message; do not start on an assumption; record a [GAP] if it cannot be supplied |
| 5 | The seller's public statements about regulatory progress: press releases, investor decks, filings, conference materials, so they can be compared with item 4. | ask in the one message; do not start on an assumption; record a [GAP] if it cannot be supplied |
| 6 | Manufacturing: every site for drug substance, drug product and testing, including contract manufacturers; inspection history (observations, warning letters, EU non-compliance statements, certificates); comparability data if the process changed. | ask in the one message; do not start on an assumption; record a [GAP] if it cannot be supplied |
| 7 | Data integrity and compliance: audit reports, self-disclosures, consent decrees or integrity agreements, product liability and litigation (the disputes already in the exclusivity register are carried over). | ask in the one message; do not start on an assumption; record a [GAP] if it cannot be supplied |
| 8 | Data-room representations and warranties the seller offers on regulatory matters, if the deal documents exist. | ask in the one message; do not start on an assumption; record a [GAP] if it cannot be supplied |
| 9 | Name of the counsel who will give the legal opinion and the regulatory reviewer. | ask in the one message; do not start on an assumption; record a [GAP] if it cannot be supplied |

Rules: if 1 to 3 are missing, ask. A document not supplied is a GAP with the consequence stated, never an inference. The company unit runs one map per pipeline asset; the roll-up lists assets side by side.
