# Output format: maturity check (findings and evidence)

Short mode: 450 words maximum, counted without tables' source column; cut in this order: context paragraphs, secondary rules, full-mode sections; offer the full version in one line. Before handing over, count the words of the answer (excluding the calls list and table source columns). If over 450, cut in this order until under: context paragraphs, repeated row ids in prose, secondary rules, rows not tied to the person's question. Never cut a gap, a stop or the record line. Refusals follow the same 450-word cap.

## Short mode (default for a direct question)

1. **Answer:** the processes with the least evidence for the period, and the one or two findings that matter most.
2. **Frame:** processes, period, scale ("your scale", "register starter rule, adopted by you", or "no scale: criteria and evidence only").
3. **Evidence by process (compact):** Process · Criteria (rows) · Evidence: seen / described / none / not applicable · Level only if your scale defines it.
4. **Findings:** only facts not already carried by the evidence table, each with process, criterion and row. Omit this section if the table carries them all.
5. **Open questions (at most three):** the scale first, then the evidence that would decide most.
6. **Record:** "Self-check draft on evidence you supplied. Not an audit. Uncleared." or the clearer's name.
7. One line offering the full version.
