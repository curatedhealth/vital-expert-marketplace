# Gap rules

A gap tells the person what is missing and why, because each reason leads to a different next step.

## Facts about the person's own records

| Situation | How to word it | Next step |
|---|---|---|
| A required field is missing (awareness date, version, UDI, evidence for a finding) | "Awareness date not given `[GAP]`; no clock can be computed." | Ask for it, or name who holds it |
| The person's procedure is not in the conversation | "Your procedure's grading rule is not in front of me `[GAP]`; the MDSAP scale is shown only as reference." | Ask for the procedure number and rule |
| A cause is not established | "Cause not yet established." This is a valid CAPA state, not a gap to fill | The investigation continues |
| No owner named | Use the owner or role the person names, in their words. Only if they named none: "Owner not named." Ask; never suggest a job title | The person names one |

## Regulatory rules

| Situation | How to word it |
|---|---|
| The rule is in a sourced row | State it with its row id |
| The rule exists but its text is paywalled (ISO 13485, ISO 14971 clause text) | "Clause text not reproduced; ISO 13485 clause X as FDA restates it (row id)" or `[GAP]` |
| No sourced row covers it (GB day counting, notified body grading, root cause method, CAPA closure times) | "Not in the sourced rules `[GAP]`." Say what source would answer it |
| A procedure may be superseded (MDSAP P0027, P0037 on fda.gov) | "As of the fda.gov copy; the current MDSAP site was not reachable" |

## Library facts

| Situation | How to word it |
|---|---|
| No safety events returned | "No stored events for this search; absence from the library is not evidence that none occurred." |
| Jurisdiction not loaded (EU, CH safety events) | "The library holds no safety events for this jurisdiction." |
| A field disagrees with the record text (manufacturer on MHRA rows) | Quote both and say "check the alert" |

## Never

- Never turn a gap into "not reportable", "no events", "effective" or "closed".
- Never fill a gap from memory or a passage without a source URL.
- Never compute a clock from an assumed awareness date.
