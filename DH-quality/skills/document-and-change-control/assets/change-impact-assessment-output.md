# Output format: change impact assessment (question sheet)

Short mode is the default for a direct question. 450 words maximum, counted without tables' source column; cut in this order: context paragraphs, secondary rules, full-mode sections; offer the full version in one line. Before handing over, count the words of the answer (excluding the calls list and table source columns). If over 450, cut in this order until under: context paragraphs, repeated row ids in prose, secondary rules, rows not tied to the person's question. Never cut a gap, a stop or the record line.

## Short mode

1. **Answer first:** which frameworks apply to this change and why (one line each, with rows). For an EU legacy device add the consequence the source names: a significant change ends the Article 120 condition (CH2); a non-significant one may be implemented without MDR certification (QX29).
2. **Answers that point toward a submission, notification or approval:** each with the question id, the person's answer, and the source's own words ("likely required", row).
3. **Answers that point toward documenting the change:** same format.
4. **Open questions:** the ids, and what would answer each.
5. **Decision:** "For the owner (NAME, or owner not named). Not decided here."
6. **Record:** "AI-assisted draft. Uncleared." or the clearer's name.

## Full mode

### Summary
Frameworks, the answers that point each way, open questions, the owner who decides.

### Device and baseline
| Item | Value | Source |
|---|---|---|
| Device and authorization | as the record states | library record URL, retrieval date; or the person |
| Most recently cleared device | K, DEN or P number | QX18, QX33 |
| PCCP authorized | the person's answer | AI US-10; library does not show it |
| EU status | legacy, MDR certificate type, notified body | the person |
| Changes since the baseline | list | QX13 |

### Question sheet (one table per framework)
| # | Question | Answer | Basis given | What the source says about this answer | Row |
|---|---|---|---|---|---|

### Field action and risk file
| Question | Answer | What the source says | Row |
|---|---|---|---|

### Context from comparable products
| Firm, product, version | Event date | Class | What the record states | Source, retrieved |
|---|---|---|---|---|
Context only; not evidence about this change.

### Open questions
Each with what would answer it.

### Record
