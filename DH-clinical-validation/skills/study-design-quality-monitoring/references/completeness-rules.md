# Completeness rules

Interpretive reference for A1. The spine is SPIRIT 2025 (CV115, [PAPER] DOI 10.1136/bmj-2024-081477): 34 minimum items (53 rows with sub-items in `spirit-2025-checklist.md`) plus a schedule diagram.

## 1. How to mark an item

| Mark | When | Rows |
|---|---|---|
| Addressed | The protocol text covers what the item wording asks; quote the locator (section, page). Partial coverage of a multi-part item is "partly addressed", naming the missing part. | SP- row for the item |
| Stated not relevant | The protocol says explicitly that the item does not apply, for example "no interim analysis planned". | CV117 |
| Missing | Neither of the above. Silence is not "not relevant". | CV117 |
| Not checkable | The section was not supplied (for example the SAP is a separate document the person did not share). | `[GAP]` |

All items are to be addressed before ethics submission (CV117). A count of addressed items describes coverage; it is not a quality score and it never makes a protocol "complete" or "compliant" in this skill's words.

## 2. Multi-part items to read closely

| Item | Parts that are often missing | Rows |
|---|---|---|
| 16 Outcomes | Each outcome: variable, analysis metric, aggregation method, time point | SP-16, CV113 |
| 19 Sample size | All assumptions behind the calculation | SP-19 |
| 21b Randomization | Restriction details kept in a separate document unavailable to those who enroll | SP-21b |
| 24a to 24c Blinding | Who is blinded; how; when unblinding is allowed | SP-24a, SP-24b, SP-24c |
| 25b Retention | Outcome data collected for those who discontinue | SP-25b |
| 27b, 27c Analysis | Who is in each analysis and in which group; missing data handling | SP-27b, SP-27c |
| 28a Data monitoring committee | Composition, independence, or why none is needed | SP-28a |
| 29 Trial monitoring | Frequency and procedures, or why there is none | SP-29 |

## 3. Beyond SPIRIT: items the rows add for this kind of trial

Check these only where the person's facts trigger them. Each is marked like a SPIRIT item.

| Trigger | What to look for | Rows |
|---|---|---|
| Any late-phase trial | A primary estimand in the protocol; main estimator and sensitivity analysis prespecified; missing data defined relative to the estimand | CV40, CV41, CV59 |
| A DHT captures any endpoint | Endpoint defined with tool, timing and combination of repeated assessments; V&V in the study population; usability; specifications; own-device provision | CV55, CV46, CV48, CV51, CV52, CV53 |
| DHT collects safety-relevant data | Safety monitoring plan for abnormal measurements | CV62 |
| Remote or decentralized visits | Visit modality fixed per visit; visit records; local HCP tasks limited to routine practice; monitoring plan covers decentralized settings | CV67, CV69, CV70, CV17 |
| Data from apps, devices or several systems | Data management plan with data origin and flow (CV68); data flow diagram (EU, CV102); source data location, the first durable electronic repository (CV60); audit trails (CV14); validated systems (CV12); contingency plan for tool malfunction (CV99) | rows inline |
| Remote or electronic consent | Identity check; real-time audio and video and downloadable protected copy (EU paper); who accesses DHT data | CV16, CV100, CV101, CV61 |
| AI intervention | Algorithm version, input data handling, human-AI interaction, performance-error analysis plan (SPIRIT-AI, 2013 numbering) | CV119, CV120, CV122 |
| Real-world data or linkage | Fitness for purpose (reliability, relevance) and the framework named; linkage prespecified with how inconsistencies are resolved | CV23, CV24, research file "Changes and conflicts" |
| Non-inferiority framework with a DHT measure | Basis for the margin when the comparator effect was not measured with a similar DHT; FDA consulted for a decentralized design | CV58, CV72 |
| EU application with decentralized elements | Summary in the cover letter | CV97 |
| US device study | Diversity action plan facts laid out for the owner the person names for regulatory status, or owner not named (requirement tied to final guidance, still draft on 19 October 2026) | PE-34, PE-36, PE-41 |
