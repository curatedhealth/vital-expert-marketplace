# Gap rules

A gap is information: each kind leads to a different next step.

## Currency and signals

| Situation | How to word it | Next step |
|---|---|---|
| Last search date not stated in the review | "Last search date not reported `[GAP]` (PRISMA item 6, ES-06)." | Ask the authors or the person; without it currency cannot be checked. |
| Only a year or month given | "Search date given as YEAR only; placed conservatively." | The script places year-only dates at 31 December and lists same-year items as unclear. |
| `check_currency` says current | "Not retracted, corrected, superseded or withdrawn in Crossref on DATE." Never "the review is current." | Check the search date separately. |
| No retraction found | "No retraction found in Crossref on DATE." | Journal page and PubMed check if the decision needs it (ES-123). |
| No newer study found by the library | "No newer study found in the library's sources on DATE (no CENTRAL or Embase)." Never "no new evidence." | A proper update search in the required databases. |
| Newer citing papers found | "Candidate new studies, not screened." | Screening against the review's criteria (ES-103). |
| Body rule not in the rows (NICE PMG36 currency, IQWiG check detail, rapid-review currency) | "`[GAP]` not in the sourced rules; read SOURCE." | |

## Appraisal

| Situation | How to word it |
|---|---|
| Item not yet rated | "Not rated (appraisers)." The script treats unrated items as not flaws and says so; report that. |
| A rating option not allowed on that item | "Rating not an AMSTAR 2 option for item N (ES-209); back to the appraisers." All 16 items, options and overall ratings are sourced (ES-208 to ES-227). |
| Paper silent on an item | "Not reported in the paper" with where you looked (section, PRISMA item). |
| Full text not available | "Abstract only; most AMSTAR 2 items cannot be assessed `[GAP]`." |
| RWD framework not chosen | "Framework not named by the person `[GAP]`; the three sourced frameworks use different terms." |
| Accuracy threshold for a digital measure | "No sourced threshold; the person's threshold, if any, is theirs." |

## Open access

When a source is open access (Europe PMC full text, publisher open access), read the full text before marking a field `[GAP]` from an abstract or a library excerpt. Write "abstract only" only when the full text is not openly available, and say where you looked.

## Never

- Never call a review "valid", "high quality" or "out of date" as the model's verdict.
- Never total AMSTAR 2 item ratings (ES-108).
- Never treat a library CEBM level as a quality rating of a review.
