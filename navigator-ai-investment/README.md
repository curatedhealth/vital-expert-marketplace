# Navigator AI investment

Install from the marketplace `curatedhealth/vital-expert-plugins`, pack `navigator-ai-investment`, version 0.1.0. Thirteen skills for a facilitated AI investment decision. They call the Ontology Navigator connector already on the account (`https://mcp.vital.expert/api/mcp/ontology-navigator`). Do not add a second connector. No key is in this pack.

Skills, in the order a decision runs:

1. frame-the-decision (0.3.2-draft) — Direction
2. size-value-at-stake (0.1.2-draft) — Direction
3. discover-outcomes (0.1.1-draft) — Outcomes
4. prioritize-outcomes (0.1.2-draft) — Outcomes
5. assess-strategic-readiness (0.1.1-draft) — Intelligence Core
6. compare-options (0.1.1-draft) — Intelligence Core
7. place-the-portfolio (0.1.1-draft) — Intelligence Core
8. plan-the-delivery (0.1.1-draft) — Execution
9. design-the-trial (0.1.1-draft) — Execution
10. plan-capability-building (0.1.1-draft) — Execution
11. track-value-realized (0.1.1-draft) — Organizational learning
12. review-the-portfolio (0.1.2-draft) — Organizational learning
13. close-the-decision (0.1.1-draft) — Decision governance
