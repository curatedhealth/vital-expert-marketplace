# Navigator AI investment pack (0.1.7)

Thirteen facilitated skills for one AI investment decision on the VITAL Ontology Navigator connector, in the order a decision runs:

1. frame-the-decision · 2. size-value-at-stake · 3. discover-outcomes · 4. prioritize-outcomes · 5. assess-strategic-readiness · 6. compare-options · 7. place-the-portfolio · 8. plan-the-delivery · 9. design-the-trial · 10. plan-capability-building · 11. track-value-realized · 12. review-the-portfolio · 13. close-the-decision

The connector is `https://mcp.vital.expert/api/mcp/ontology-navigator`. Paste one `vont_` key at install (`navigator_key`). Do not add a second connector. Method steps that need tools name them; local scripts cover offline checks.
