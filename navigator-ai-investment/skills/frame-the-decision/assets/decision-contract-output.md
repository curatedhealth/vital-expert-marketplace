# Output format: the full report (Decision Contract) and the direct answer

The session ends with the full report below, delivered in one go (references/facilitation.md). During the session, use the turn template only. The direct answer format is for a narrow question asked outside a session.

## Direct answer (narrow questions only)

Aim for 150 to 300 words.

1. **The decision:** one sentence in the owner's accepted wording, or "proposed:" if not yet accepted. Owner named.
2. **What it will turn on:** two or three questions, labeled hypothesis.
3. **Why it matters:** the strategic goal in one line, and the value theme chosen, if any.
4. **Size:** one line per criterion with the group view and range, the composite, and what it points to (only if scored).
5. **What we know, then the gaps:** known facts with evidence class first; at most three gap lines last.
6. **Record:** one line ("Draft prepared with an AI assistant. Uncleared." or "Cleared by NAME").

End with one offer: continue the session, or write up the full report now with what is known.

## Full report (Decision Contract)

Written for someone who was not in the conversation. Open with a three-line summary: the decision, the goal, the size and what it points to. Then the sections below.

### 1. The decision

| | |
|---|---|
| Decision statement | One sentence, owner's accepted wording |
| Original wording | As first asked, for traceability |
| Decision owner | Name and role |
| By when | As stated, or `[GAP]` |
| Reversibility | In words, from task C |
| Options already on the table | As named by the person, plus "do nothing" and "do it internally" |

### 1b. What the decision will turn on

Two or three questions, each labeled hypothesis (H), handed to the outcome and option work.

### 2. Strategic goal

| | |
|---|---|
| Goal | One sentence, with evidence class (O or V with source) |
| Value theme | Display name and dimension, chosen by NAME; or `[GAP]` |
| Objectives carried to outcomes | Any numeric objectives the person gave, labeled for the outcome work |

### 3. What a wrong call costs

In the owner's words, qualitative. "The money range is set in Value-at-Stake Sizing."

### 4. Size of the decision

| Criterion | Group view (1 to 10) | Range across scorers | Owner's view |
|---|---|---|---|
| Stakes | | | |
| Reversibility (10 = easy to reverse) | | | |
| Commitment horizon | | | |
| Functions involved | | | |
| **Composite** | | | |

Scorers: names. Missing: names, or none. Disagreement to discuss: criteria where scorers were far apart.

**What the size points to:** the matching signal and why, and the owner's choice of format.

**Field-test questions (for outcome work):** (a) hard to reverse? owner's answer. (b) commits money or people beyond one planning cycle or across functions? owner's answer.

### 5. What is already known

| Fact | Evidence class | Source |
|---|---|---|

Main unknowns, each `[GAP]` with what would close it.

### 6. Record

- Draft prepared with an AI assistant on DATE.
- Accepted by the decision owner: yes / not yet.
- Cleared by NAME, or "uncleared draft".
- Brief opened in the Navigator: brief reference, or "not opened".
