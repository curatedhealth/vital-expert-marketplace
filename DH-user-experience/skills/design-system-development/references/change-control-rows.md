# Change control rows (excerpt from QUALITY_SYSTEMS.md)

Use: a design-system component that is part of a medical device user interface is device software, so a change to it is a design change handled under the manufacturer's change control. These rows say what the regulators state about that. Whether a change is significant, and what a submission needs, is decided by the person's regulatory and quality owners (dh-regulatory-strategy, dh-quality document-and-change-control).
