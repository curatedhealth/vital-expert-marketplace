# Output format: control and field-signal check

Short mode: 450 words maximum, counted without the calls list and tables' source column. Before handing over, count the words. If over 450, cut in this order until under: context paragraphs, repeated row ids in prose, secondary rules, rows not tied to the person's question. Never cut a gap, a stop or the record line. Refusals follow the same 450-word cap.

## Short mode (default for a direct question)

1. **Answer:** controls missing or changed type on critical tasks in the named build; the one field signal that matters most.
2. **Frame:** build version, controls in scope, markets, period.
3. **Controls (compact):** Control · Use error it answers · Type designed / shipped · Status (present seen / present described / missing / changed type / needs data) · Evidence and date.
4. **Field signals you hold:** source, count, denominator, date.
5. **Comparable events (if run):** product as stated · date · class or alert type · summary words · prompt for you. "Sorting is ours. The tool has no use-error filter. No inference about these products." Coverage: state the list_jurisdictions counts for every market the person sells in, including EU 0 and CH 0 where relevant, with any [GAP] note the tool returns for that market (CH: Swissmedic notices not loaded); absence of events is not evidence of safety.
6. **Calls made:** each with arguments.
7. **Record:** "Control and field check draft on build NAME. Uncleared until a named person clears it through verify.build_record. AI-assisted."
8. One line offering the full version.
