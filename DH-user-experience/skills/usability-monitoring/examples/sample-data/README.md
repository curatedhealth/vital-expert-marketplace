# Sample data (illustrative)

These files are illustrative, written for this skill on 19 October 2026. They are not real test data.

- `usability_log_illustrative.csv`: 14 participants (8 nurses, 6 pharmacists) by 4 tasks; severity and the critical flag as a person would assign them; one row deliberately left without severity.
- `sus_illustrative.csv`: ten SUS answers per participant.
- `log_summary_output.txt` and `sus_output.txt`: output of `scripts/usability_log.py` on these files.
