# DH Diligence

Install **DH Diligence** from `curatedhealth/vital-expert-plugins`, then paste the Digital Health Library key. The key is not in this pack.

This pack is the Digital Health Library diligence suite. No CF-12 core is named Diligence, so these skills are library jobs, not register codes.

The connector is `https://mcp.vital.expert/api/mcp/library`. Do not add a second connector.

Choose one job. The job holds its tools as sections. Ask which one task, then follow that section. A missing fact stays a gap.

Library job investment-memo is for design partners. Do not start it.
