# Regulatory Strategy & Submissions

Install this plugin from the VITAL marketplace, then paste the Digital Health Library key Cowork asks for. The key is not in this repository. It is the same key as Evidence and Reimbursement.

## Install

1. In Cowork, open Customize, then Plugins, then Add marketplace.
2. Enter `curatedhealth/vital-expert-plugins`.
3. Install **Regulatory Strategy and Submissions**.
4. When Cowork asks for the Digital Health Library key, paste the `vlib_` key from your purchase.
5. Leave the plugin switched on.

The connector is `https://mcp.vital.expert/api/mcp/library`. You do not add a second connector.

## Use it

Ask for the pack. It opens on four headings:

- AI/ML Regulatory
- Global Harmonization
- Regulatory Strategy
- Submission Excellence

Choose one heading, then one job. The job loads one task. A task calls the library only when that task names a tool. A missing fact stays a gap.

The library tools in this pack search devices, open one authorization, compare authorizations, read market status, classify a product, read pathway precedents, find United States predicates, watch a register, read what that watch recorded, search safety events, list the loaded registers, retrieve stored guidance, and generate a pathway report. `get_deltas` is the same call as reading register changes.

Finding an expert is free. Downloading one expert is one counted call on the same key.

## The key

The key is the purchase. It carries a monthly call cap. Menu calls such as listing jobs are not counted. A successful tool call spends one unit. Verify can spend several units on one task. When the cap is reached, or the purchase ends, the tools stop. The installed plugin remains.
The skills run only while the Digital Health Library connector is connected. Turning the plugin off removes the skills and the connector together.
