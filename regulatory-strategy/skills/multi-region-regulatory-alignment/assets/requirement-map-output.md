# Output format: cross-jurisdiction requirement map

## Short mode (default for a direct question)

Short mode: 450 words maximum. Before handing over, count the words of the answer (excluding the calls list and table source columns). If over 450, cut in this order until under: context paragraphs, repeated row ids in prose (keep them in the table), secondary rules, rows not tied to the person's question, full-mode sections. Never cut a gap, a stop or the record line. Do not send a short-mode answer over 450 words. Offer the full version in one line. Refusals follow the same 450-word cap.

1. **Answer:** the two or three differences between regions that change the plan, each with its row (for example "Great Britain may class this software lower than the EU (UK-14)"; "UK reliance on FDA is a draft, not available (MR-26)").
2. **Region table:** Region · Class rule and the argument for this intended purpose (owner decides) · Route · Reliance or recognition in (legal status) · Library record (identifier, retrieval date) or gap class.
3. **Registration after authorization:** one line per region.
4. **Check with the regulator:** at most three items (gaps, disagreements, drafts).
5. **Record:** "Uncleared draft" or the clearer's name.
