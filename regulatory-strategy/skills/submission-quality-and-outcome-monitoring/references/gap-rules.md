# Gap rules

A gap is information: the person needs to know why something is missing, because each reason leads to a different next step.

## Dossier completeness (A1)

| Class | When | How to word it |
|---|---|---|
| Present | The draft has a section that matches the map line. | "Present (section X, page Y)." Presence is not quality. |
| Present, thin | The section exists but a sub-item the source names is not found (for example no rationale for the documentation level, S-01). | "Present; sub-item not found: ..." with the row. |
| Missing | The map names the section and the draft has nothing for it. | "Missing" with the row. |
| Applicability open | The source says "if applicable". | "If applicable (source wording); the regulatory owner rules." |
| `[GAP]` not checkable | The draft points to an annex or file not supplied. | "`[GAP]` referenced file not supplied." |
| Not in the map | The draft has a section the map does not name. | "Not in the source map; no finding." |

## Clocks and outcomes (A2)

| Situation | How to word it |
|---|---|
| The person gave no event dates | "FDA days cannot be counted without the received, hold and response dates `[GAP]`." |
| A figure's basis is unclear | Say which: FDA days, calendar days, goal, actual, cohort year. If unknown, `[GAP]`. |
| Comparable median from the library | "Calendar days between the record's dates, n = N, pathways mixed" until split. |
| EU time to certificate | "Not in the library (EUDAMED decision dates empty); notified body survey context, contractor study." |
| Deadline not sourced | "`[GAP]` in the files read; the letter's own timeline governs." |
| Open cohort | "FY 2026 cohort still open; not comparable." |

## Performance review (B1)

| Situation | How to word it |
|---|---|
| No rule set by the person | Factual summary, no verdict. |
| Rule set but not measurable | "Not measurable `[GAP]`" and what data would measure it. |
| No owner named | "Owner not named" and ask. |

## Never

- Never turn a gap into "rejected", "failed", "late" or "at risk". A miss is a measured result against a rule the person set.
- Never fill a gap from memory, from a passage without a source URL, or from a standard's clause text.
- Never read absence from the library as absence of an authorization.
