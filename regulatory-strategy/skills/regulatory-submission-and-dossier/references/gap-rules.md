# Gap rules

A gap is information: each kind of gap leads to a different next step.

## Dossier sections

| Class | When | How to word it | Next step |
|---|---|---|---|
| Ready | The person says the section is ready and names the file. | "Ready (person's word), file X, owner Y." | None from the model; the owner confirms. |
| Draft | The person says it is in progress. | "Draft, owner Y." | The owner sets the finish point. |
| Missing | The person says it does not exist yet. | "Missing, owner Y" or "Missing, owner not named". | Ask who owns it. |
| Not in the inventory | The source names the section but the person did not mention it. | "`[GAP]` not in the inventory." | Ask whether it applies and who owns it. |
| Applicability open | The source says "if applicable". | "If applicable (source wording); the regulatory owner rules." | Ask the regulatory owner. |
| Not in the map | The person has an item the source map does not name. | "Not in the source map; ask where it belongs." | Regulatory owner places it. |
| Source not read | The route's content structure is not in the reference rows (PMA content, UKCA technical documentation, Swiss specifics). | "Content structure not sourced in this skill `[GAP]`." | Read the regulator's guidance before building the map. |

## Clinical evidence

| Situation | How to word it |
|---|---|
| No results passage read for a claimed finding | "Not checked: no results passage `[GAP]`." Never "supported". |
| Library returned a design label or level only | "Draft label from the library (decided by title text)." |
| Conference abstract or preprint | Say so in the row; it is not a peer-reviewed full report. |
| Equivalence claimed without data access shown | "Equivalence not shown: data access `[GAP]` (S-76)." |

## Agency facts

| Situation | How to word it |
|---|---|
| A clock exists but is not in the rows read | "`[GAP]` in the files read" with what to read. |
| Library guidance store returns nothing relevant | "The library holds no passage for this; the map is from the reference files." |
| EU authorization not found | "Not found in the library's EUDAMED copy", never "not authorized". |

## Never

- Never mark a section ready, complete or adequate on the model's own judgment.
- Never fill a gap from memory, from a passage without a source URL, or from a standard's clause text.
- Never name an owner the person did not name.
