# Status vocabulary (v0.2)

| Status | Meaning |
|---|---|
| `findings_only` | Work in progress; not ready for board (no approval / bypass pressure) |
| `revise` | Material changes required before board |
| `human_gate_required` | A request to approve or clear, or to bypass any hard rule MLR-H1–H8 (precedence rule 1), or an open finding a human must judge. Order: `../../../references/finding-status-map.md` |
| `prep_complete` | Packet validated for human MLR review — **not** approved for use |

Forbidden in any field: approved for use, mlr approved, mlr_reviewed true, compliant with, cleared for promotion.
