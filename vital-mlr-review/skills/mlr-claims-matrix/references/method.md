# Method — MLR claims matrix

1. Run intake for missing fields.
2. Prefer offline tools (`python ../../tools/mlr_claims_matrix_offline.py`).
3. Fill `claims-matrix-card.md` only with supplied facts.
4. Name `[GAP]` instead of inventing.
5. Stamp with `python ../../tools/stamp_ready_line.py --skill mlr-claims-matrix --letter-lines`.

Hard stops: empty jurisdictions when markets needed; approval language; simulating VERIFY.
