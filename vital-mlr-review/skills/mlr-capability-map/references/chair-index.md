# Chair index — when to route where

| Reader question | Chair skill | Primary standards family |
|---|---|---|
| Does this match the label / SmPC / FI? Are benefits fairly balanced clinically? | `mlr-medical-chair` | FDA labeling communications; Directive 2001/83 medical content; ABPI/EFPIA clinical; HWG/AMG clinical; Swissmedic medical |
| Could this mislead, unfairly compare, or create privacy/IP exposure? | `mlr-legal-chair` | 21 CFR 202 misleading frame; Directive prohibitions; EFPIA/ABPI comparative; HWG; Swiss TPA/Pharma Code |
| Is ISI/brief summary present? Pre-approval promo? Code process? Right audience/channel? | `mlr-regulatory-chair` | FDA promo format; Directive/EFPIA process; ABPI + MHRA Blue Guide; HWG/AMG/FSA; Swissmedic process |

If the request spans two chairs, name both and the order (usually Medical → Legal → Regulatory, unless format classification is blocking Medical).
