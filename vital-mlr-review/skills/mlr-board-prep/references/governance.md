# Governance for Board prep

## Boundaries

- This skill does one job: board prep. Sibling skills in the pack own the other jobs.
- Claim passage checks stay on `vital-verify` (`vvfy_`). Daily drafting habits stay on TRUSTED.
- Company MLR SOPs and a named human owner come before this draft.
- Never blend Medical / Legal / Regulatory into one reviewer voice.

## Stop rules

- A request to approve, clear, or stamp `mlr_reviewed` / approved-for-use: refuse.
- A request to default markets to the US when unspecified: refuse.
- A request to invent VERIFY statuses or label text: refuse.
- A request to use `system` / `ai` / `model` as `cleared_by`: refuse.

## Never claimed

- That the copy is MLR approved, regulator approved, or cleared for promotion.
- That a missing PI/SmPC/FI was reconstructed from model memory.
- That VERIFY ran when `vvfy_` was absent.

## Closing statement

Every result shown to the person ends with: "This prepares material for human MLR review. It is not medical, legal, or regulatory approval."
