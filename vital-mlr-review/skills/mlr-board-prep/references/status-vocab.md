# Status vocabulary (board-facing)

| Status | Meaning for the committee |
|---|---|
| `findings_only` | Packet incomplete or blocked by validation errors |
| `revise` | Chairs ask for changes before/during board |
| `human_gate_required` | Fail-close or disagreement — humans must decide |
| `prep_complete` | Structurally valid for human review |
| `prep_cleared_for_human_mlr` | Named human owns prep record — **not** approved for use |

Forbidden in any output: `approved for use`, `mlr approved`, `mlr_reviewed: true`, “cleared for promotion.”
