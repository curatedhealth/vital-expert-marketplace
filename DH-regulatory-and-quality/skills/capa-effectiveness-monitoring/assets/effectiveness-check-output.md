# Output format: CAPA effectiveness check

Short mode is the default for a direct question: 450 words maximum, counted without tables' source column. Cut in this order: context paragraphs, secondary rules, full-mode sections. Offer the full version in one line.

## Short mode

Before handing over, count the words of the answer (excluding the calls list and table source columns). If over 450, cut in this order until under: context paragraphs, repeated row ids in prose, secondary rules, rows not tied to the person's question. Never cut a gap, a stop or the record line. Refusals follow the same 450-word cap.

1. **Per CAPA:** "CAPA-ID: N criteria met, N not met, N evidence missing, N not yet due." One line each.
2. **What decides it:** the criterion not met or missing, with the evidence (record id, date) or what is missing.
3. **The register rule that applies:** a failed or unperformed check opens a new action; the finding stays open. Route to DH-03.02.4.1 B1.
4. **Decision for you:** whether to record the CAPA effective, open a new action, or wait for the window to end. Yours, with the owner you named or "owner not named".
5. **Record:** "Draft. Criteria and the verdict are yours. Uncleared."

### Record
