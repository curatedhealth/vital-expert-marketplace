# Gap rules

A gap is information. Each reason for a gap leads to a different next step, so name the reason.

## Requirement facts

| Class | When | How to word it | Next step |
|---|---|---|---|
| Sourced | A research row states it. | The fact plus the row id (for example "QMSR effective 2 February 2026, QS1"). | None. |
| Clause number only | The duty sits in an ISO 13485 clause and the rows give FDA's clause number but not the text. | "ISO 13485:2016 clause 5.6.1 to 5.6.3 (FDA CP 7382.850, BX7); clause text not quoted `[GAP]`." | Read the free read-only copy (ST13) or the person's licensed copy. |
| Market not in the research | The person targets a market the rows do not cover for QMS (for example the GB QMS requirement). | "The QMS requirement for this market is not in this skill's sources `[GAP]`." | Ask the regulatory owner, or the Regulatory pack. |
| Version caveat | A row says its source may be superseded (MDSAP documents moved, QS39; MDR consolidation of 10 January 2025). | State the version read and the caveat in one line. | Check the current version before relying on it outside the conversation. |
| Draft or proposal | A row describes a proposal or draft (UK reliance, MR-24 to MR-26). | "Proposal, not in force as of the research read on 19 October 2026." | None; do not plan on it as law. |

## The person's facts

| Situation | How to word it |
|---|---|
| Device class or market not stated | Ask. If the answer is unknown, write "class not stated `[GAP]`" and do not pick the requirement set for that market. Classification belongs to the person's regulatory owner. |
| No owner named for a process | Use the owner or role the person names, in their words. Only if they named none, write "owner not named" and ask. Never suggest a job title. |
| No cadence stated | Leave the cadence blank and ask; list the external clocks (EU25, QS42) as facts beside it. |
| No scores for B1 | No ranking. Lay out the facts per option and ask the person to score. |

## Library facts

| Situation | How to word it |
|---|---|
| No safety events returned | "No events in the library for this query; absence is not evidence of no events." |
| Guidance passage without a source URL | Do not use it. |
| Jurisdiction closed in the library | "The library does not load this jurisdiction (reason as returned)." |

## Never

- Never fill a requirement, clause text, class, owner, score or cadence from memory.
- Never treat a missing row as "not required".
