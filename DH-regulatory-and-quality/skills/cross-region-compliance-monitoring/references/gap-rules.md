# Gap rules

A gap is information. The person needs to know why something is missing, because each reason leads to a different next step.

## Market status from the library

| Class | When | How to word it | Next step |
|---|---|---|---|
| Found | `search_devices` returns a record. | Class and pathway as recorded, identifier, decision date where stored, retrieval date. | None. |
| Field missing | The record exists but a field is empty (every EU decision date). | "On the EU market per EUDAMED record ++B720EASPECTSCEGK; no decision date stored `[GAP]`." | Check the register entry. |
| Register loaded, product not found | Records exist for the jurisdiction but none for this product. | "Not in the library's copy (N records, loaded DATE)." | Check the regulator before concluding. |
| Register loaded, not searchable | Canada. | "The library holds MDALL rows but cannot search them by product." | Check MDALL. |
| Register not loaded | GB registration, Switzerland, Australia, Brazil, Japan. | "The library holds no device registrations for this region." | Check the regulator. |

## Change over time

| Situation | How to word it |
|---|---|
| Delta log empty, no watch | "No change recorded; the log has not started for this scope." Never "no change". |
| Two of your own runs differ | State both runs with their dates and what changed. |
| A guidance passage has no source URL | Do not cite it; say the library holds it without provenance. |
| Status of a document unknown | "Status not established `[GAP]`; check the regulator's page." |

## Obligations

| Situation | How to word it |
|---|---|
| No research row sources the duty | "`[GAP]`: not in the sourced references", and name the regulator to check. |
| A date passed | "Date passed N days ago: confirm what was filed." Never "missed". |
| The person has not given an input the date depends on (certificate issue date, first placing date) | "Depends on DATE not given `[GAP]`"; ask. |
| A proposal would change a date | Keep the date in force; add the proposal as a separate line with its status. |

## Never

- Never turn a gap into "not authorized", "lapsed", "non-compliant" or "missed".
- Never fill a gap from memory.
