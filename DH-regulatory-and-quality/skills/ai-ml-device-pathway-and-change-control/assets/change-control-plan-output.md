# Output format: change control plan (PCCP structure)

## Short mode (default for a direct question)

**Short mode: 450 words maximum, counted without tables' source column; cut in this order: context paragraphs, secondary rules, full-mode sections; offer the full version in one line.** Before handing over, count the words of the answer (excluding the calls list and table source columns). If over 450, cut in this order until under: context paragraphs, repeated row ids in prose, secondary rules, rows not tied to the person's question. Never cut a gap, a stop or the record line. The calls list is not counted.

1. **Answer:** whether a PCCP can exist on this route [AI US-09], and how the planned changes sort, in two or three sentences.
2. **One table, sorting:** Planned change (your words) · Closest FDA type · Intended-use check · Sort (owner to confirm).
3. **To supply first:** at most three items, each with the heading it fills.
4. **Record:** "Structure only. Acceptance criteria and scope are set by the owner. Draft for the owner. Uncleared."

## Full mode

### Answer
Can a PCCP be established in the planned submission; which changes sort where; the biggest open item.

### Sorting of planned changes
| # | Planned change (your words) | Closest FDA type [AI US-07] | Intended-use check [AI US-08] | Sort |
|---|---|---|---|---|

### Description of Modifications [AI US-04]
Per change: what changes; specification to be met: set by the person `[GAP]`; populations and inputs in scope.

### Modification Protocol [AI US-05]
Per change: data management; retraining; verification and validation; acceptance criteria: set by the person `[GAP]`; update procedure; labeling update; post-market monitoring [AI US-36]; detect and revert [AI US-31].

### Impact Assessment [AI US-06]
| Change | Risk (your words) | Mitigation (your words) | Benefit-risk conclusion (owner) |
|---|---|---|---|

### Section 515C placeholders [AI US-17]
Labeling; notification if the device does not function as intended; performance requirements.

### Placement and use
Standalone, titled, versioned section [AI US-11]; implementation and documentation after authorization [AI US-12]; deviation consequence [AI US-13].

### EU and UK (if asked)
Article 43(4) and Annex IV point 2(f); MDCG 2025-6; no EU PCCP guidance yet; MHRA draft guidance announced.

### What you must supply
Numbered list, each item with the heading it fills and the owner (or "owner not named").

### Record
Draft for the owner. Cleared by NAME, or uncleared. AI-assisted draft.
