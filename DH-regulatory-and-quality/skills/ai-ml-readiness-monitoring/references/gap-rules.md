# Gap rules

A gap is information, not an apology. Each kind leads to a different next step.

| Class | When | How to word it | Next step for the person |
|---|---|---|---|
| Not assessable | The person has not shown or named the item | "Not assessable: not shown `[GAP]`." | Point to where it is, or mark it missing |
| Missing | The person says it does not exist yet | "Missing." | Owner and dependency in B1 |
| Missing from a list the person gave | The person lists an item's parts (for example PCCP components) and a required part is not on the list | "Missing from the list you gave; confirm." No [GAP] tag: the requirement is sourced. | Count it as missing; owner confirms |
| Not yet applicable | The requirement starts later (with the act that set the date) | "Not yet applicable: from DATE (ACT)." | Plan by dependency |
| Requirement not in references | No row states the requirement | "Not in the sourced references `[GAP]`; authority: AUTHORITY." | Read the authority's text |
| Requirement unsettled | Draft guidance, a legal question the research flags (Article 72 timing), or announced guidance | "Unsettled: REASON, source DATE." | Owner decides how to plan |
| Library not loaded | Jurisdiction has no events or registrations in the library | "The library holds no EVENTS for JURISDICTION." | Check the regulator's database |
| Library result off-target | A returned record does not name the product or a comparable | "Returned but not about this product; excluded." | None |

## Never

- Never turn "not assessable" into "missing", or "missing" into "non-compliant".
- Never read an empty safety search as "no safety issues".
- Never fill a gap from memory, from an ISO or IEC clause, or from a passage without a source URL.
- Never grade quality: a present item is present, not "adequate".
- Never report "0 missing" while naming a missing item; counts and headline must agree.
