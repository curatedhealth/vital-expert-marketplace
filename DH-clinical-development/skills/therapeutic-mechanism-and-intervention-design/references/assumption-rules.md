# Assumption and stopping rules

Interpretive reference for B1. Every rule cites its row in `therapeutic-mechanism-research.md` (TM). The sources say milestones are set in advance and tied to clinical significance; they do not give the numbers. Every threshold, milestone and stopper is the person's.

## 1. Find the assumptions

| Rule | Rows |
|---|---|
| Key uncertainties are a core element at every phase; a program can start at any phase depending on them. | TM2, TM4 (MRC/NIHR, DOI 10.1136/bmj.n2061) |
| Ask the framework's question: "What are the key uncertainties?" | TM5 (MRC/NIHR, DOI 10.1136/bmj.n2061) |
| Each link in the A1 chain carries at least one assumption: the component is delivered, the user acts, the action produces the change, the change moves the outcome, the chain holds in this population. | TM6, TM8 (MRC/NIHR, DOI 10.1136/bmj.n2061), TM84 (JITAI, DOI 10.1007/s12160-016-9830-8) |
| Unreliable or invalid tailoring variables are an assumption in every adaptive rule. | TM88 (JITAI, DOI 10.1007/s12160-016-9830-8) |
| Process evaluation covers fidelity, mechanisms and context; a quantitative trial alone is rarely adequate for complex interventions. Name which assumptions only a process evaluation can test. | TM17 (MRC/NIHR, DOI 10.1136/bmj.n2061), TM91 (Moore, DOI 10.1136/bmj.h1258) |

## 2. Write the signal that shows it is wrong

| Rule | Rows |
|---|---|
| A feasibility study tests predefined progression criteria about the evaluation design (recruitment, data collection, retention, outcomes, analysis) or the intervention (content, delivery, acceptability, adherence, likelihood of cost-effectiveness, provider capacity). | TM14 (MRC/NIHR, DOI 10.1136/bmj.n2061) |
| Before feasibility, consider an evaluability assessment: expected outcomes, data available, design options. | TM15 (MRC/NIHR, DOI 10.1136/bmj.n2061) |
| Milestones are specified a priori and on clinical, not statistical, significance; this prevents "moving the target" after the data are in. | TM57 (ORBIT, DOI 10.1037/hea0000161) |
| Implementation strategy and intervention outcomes are pre-specified, with any pre-determined targets documented. | TM118 (StaRI, DOI 10.1136/bmj.i6795) |
| Name the measure for each signal; a signal with no measure is `[GAP]` and becomes work for the monitoring skill's check plan. | TM97 (Moore, DOI 10.1136/bmj.h1258) |

## 3. Name what happens and who decides

| Gate in the sources | What the source says happens | Rows |
|---|---|---|
| ORBIT Ia to Ib | Move once pathway, candidate components, per-component targets and milestones are defined | TM58 (ORBIT, DOI 10.1037/hea0000161) |
| ORBIT I to II | Move when the package is complete, efficient, safe, acceptable and plausibly clinically significant (ORBIT words this as the investigator's confidence; who judges it is the person the user names, or owner not named) | TM60 (ORBIT, DOI 10.1037/hea0000161) |
| ORBIT IIa | If the clinical criterion was not even approached, return to Phase I or decide whether to abandon. Applies to clinically significant change on the target, not to engagement or adherence links; for those use the feasibility progression criteria (TM14). | TM62 (ORBIT, DOI 10.1037/hea0000161) |
| ORBIT IIb to III | A clinically significant signal while the control shows none, plus a feasible recruitment plan, dropout estimates and an effect-size range | TM64 (ORBIT, DOI 10.1037/hea0000161) |
| MOST evaluation | If the best feasible package is too weak, return to preparation; an RCT is needed when an effect-size estimate is wanted | TM73 (MOST 2016, DOI 10.1007/s10461-015-1145-4) |
| MRC/NIHR | Repeat a phase rather than progress automatically while uncertainties remain | TM3 (MRC/NIHR, DOI 10.1136/bmj.n2061) |
| Refinement | Refinements follow the program theory within boundaries agreed at the start of each phase; rare during efficacy or effectiveness evaluation | TM13 (MRC/NIHR, DOI 10.1136/bmj.n2061) |

ORBIT does not require starting at Ia or evidence for every link (TM65). Name which gate model the person uses; do not impose one.

The old task rule stays: the stopping rule names who stops the version. That is the owner the person names, in their words, or "owner not named". Never a role the model chose.
