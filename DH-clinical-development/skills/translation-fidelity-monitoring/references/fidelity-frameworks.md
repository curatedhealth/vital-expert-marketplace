# Fidelity frameworks

Interpretive reference for tasks A1 and A2. TM rows read 20 October 2026; CS rows 19 October 2026. DOIs travel with the rows as listed in SKILL.md. Where a fact is not in a row, it is `[GAP]`.

## 1. Definitions

| Term | Definition | Rows |
|---|---|---|
| Implementation fidelity | The degree to which programs are implemented as intended by the program developers; it moderates the link between intervention and outcomes. | TM100 |
| Fidelity (Proctor) | The degree to which an intervention was implemented as prescribed in the original protocol or as intended by the developers. | CS37 |
| Fidelity and dose (Moore) | Fidelity: delivered as intended. Dose: quantity implemented. | TM92 |
| Reach | Whether and how the intended audience comes into contact with the intervention. | TM94 |
| Treatment fidelity (Bellg, abstract only) | Methodological strategies to monitor and enhance reliability and validity of behavioral interventions. | TM99 |
| Implementation (RE-AIM, official site) | At setting level, agents' fidelity to the protocol; at individual level, clients' use of the intervention strategies. | CS25 |

## 2. The frameworks disagree: name the one used

The research file records the conflict (Changes and conflicts item 3): Moore states there is no consensus on how to divide implementation into fidelity, dose and reach (TM94); Carroll measures fidelity as adherence and treats quality of delivery and responsiveness as moderators, while the literature it reviewed counted five elements (TM101 to TM103); Bellg uses five different areas (TM99, abstract only). Every output names the framework it uses.

| Framework | Parts | Rows |
|---|---|---|
| Carroll 2007 (DOI 10.1186/1748-5908-2-40) | Measure: adherence, with subcategories content, frequency, duration, coverage (dose). Moderators: intervention complexity, facilitation strategies, quality of delivery, participant responsiveness. Content is the active ingredients. | TM102 to TM104 |
| Literature reviewed by Carroll | Adherence, exposure or dose, quality of delivery, participant responsiveness, program differentiation. | TM101 |
| Moore 2015 (DOI 10.1136/bmj.h1258) | Implementation, mechanisms, context; fidelity, dose, reach; integrate process data with outcomes; report the logic model. | TM91 to TM97 |
| Bellg 2004 (abstract only, DOI 10.1037/0278-6133.23.5.443) | Study design, provider training, treatment delivery, treatment receipt, enactment of treatment skills. The strategies per area were not read. | TM99 |
| StaRI (DOI 10.1136/bmj.i6795) | Report fidelity to the implementation strategy and its adaptations, and fidelity to the intervention's core components. | TM116 |

For software delivery, Carroll's adherence subcategories map onto logged data (modules delivered, sessions, minutes, users reached). That mapping is this skill's proposal, not a source statement; label it "proposed".

## 3. Core components, adaptation and variation

| Rule | Rows |
|---|---|
| Deconstruct the intervention into components and agree permissible and prohibited variation in advance. | TM11 |
| Standardization can apply to function rather than form. | TM12 |
| Refinements stay within boundaries agreed at the start of each phase, with the rationale reported; rare during efficacy or effectiveness evaluation. | TM13 |
| Flexibility in implementation is acceptable if key functions are kept and adaptations understood. | TM19 |
| Define core components (tied to the logic pathway) where fidelity is expected and aspects sites may adapt. | TM117 |
| CFIR: adaptability relies on separating core components from the adaptable periphery (DOI 10.1186/1748-5908-4-50). | CS4 |
| CFIR: quality of execution includes fidelity to planned courses of action. | CS9 |
| ERIC: identify how an innovation can be tailored and which elements must be maintained to preserve fidelity (DOI 10.1186/s13012-015-0209-1). | CS48 |
| Fidelity may be met by delivering only essential components, if they are identified, for example by component analysis across studies. | TM105 |
| Detailed, specific interventions are more likely to be implemented with high fidelity than vague ones. | TM106 |
| A fixed treatment manual is the basis for training, supervision and fidelity monitoring. | TM61 |
| Scalable means implementable with fidelity without ad hoc cuts of unknown effect. | TM70 |
| Comparing delivery with the intervention theory separates fit-to-context adaptations from changes that undermine fidelity. | TM93 |

The research file notes Carroll records an argument that the case for local adaptation "may well have been exaggerated" (Changes and conflicts item 4). Which variation is permitted is the person's decision.

## 4. Delivery measures

| Measure | What it needs | Rows |
|---|---|---|
| Content delivered | Module or lesson logs against the specification | TM102, TM104 |
| Frequency and duration | Sessions and minutes against the regimen (TIDieR item 8) | TM29, TM102 |
| Coverage or reach | Users with any use over the eligible or enrolled denominator | TM94, TM102, CS27 |
| Fidelity assessment plan | How fidelity is assessed and maintained (TIDieR item 11); extent delivered as planned is reported after delivery (item 12) | TM32, TM33 |
| Engagement and fatigue | Proximal outcomes for adaptive interventions | TM87 |
| Process evaluation in the full rollout | A feasibility-stage evaluation does not replace one alongside the full trial | TM98 |

RE-AIM computes reach on a valid denominator of eligible people (CS27); implementation measures include percent of "perfect" delivery completed (CS29). Thresholds for any measure are the person's.
