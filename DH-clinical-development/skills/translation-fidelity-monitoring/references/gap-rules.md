# Gap rules

A gap is information. Each reason for a gap leads to a different next step, so name the reason.

## Rule facts

| Class | When | How to word it | Next step |
|---|---|---|---|
| Sourced | A research row states it | The fact plus the row id ("fidelity measured as adherence, TM102") | None |
| Published method | The row is [PAPER] | "Carroll adherence (TM102), DOI 10.1186/1748-5908-2-40" | Cite the DOI |
| Abstract only | Bellg (TM99) | "Bellg five areas, abstract only (TM99)" | Do not rely on strategies not in the abstract |
| Frameworks disagree | Fidelity parts (research file conflicts item 3) | "Using Carroll's framework; Moore and Bellg divide it differently" | Name the framework |
| Nonbinding guidance | FDA CFL guidance | "FDA considers (nonbinding guidance, PC-US-23)" | Do not present as law |
| Not in the sources | Any fidelity threshold, sample size for a claim audit, acceptable adherence level, Bellg strategies, the BfArM change checklist content | "Not in this skill's sources [GAP]; the person's rule" | Ask the person or the owner they name |

## Sample facts

| Situation | How to word it |
|---|---|
| Claim with no source passage | "No source passage on file"; a fail if the person adopts the old DH-01.01.4.2.2 rule |
| Sample smaller than the shipped set | "Sample n of N shipped; drawn by [the person's method]"; never a sample of only matching claims |
| Shipped count unknown | "Number shipped not given [GAP]" |
| Verify returns "supported" | Recorded with its overlap; never a pass on its own (N3) |
| Verify rates a source inadmissible | "Verify could not admit this source (C1); compared by hand" |
| Rule behavior without evidence | "Observed behavior not evidenced [GAP]; test record or log needed" |
| Usage log without module data | "Content delivered not measurable [GAP]; frequency and duration only" |
| Session not defined | "Session unit not defined [GAP]"; dose figures wait for it |
| Recall or MAUDE count | "Recall summary as recorded"; "report counts, not confirmed events" |

## The person's facts

| Situation | How to word it |
|---|---|
| No pass rule given | "Rule not set; difference quoted for the person to mark" |
| No threshold | Column left blank; no figure called adequate or low |
| No owner named | "Owner not named"; ask. Never suggest a job title |
| Version not named | "Version not stated [GAP]"; the sample cannot be filed against a release |

## Never

- Never mark a claim faithful because a citation is present or Verify returned "supported".
- Never set a fidelity threshold, adherence level or sample size from memory.
- Never describe a difference as misconduct or intent.
