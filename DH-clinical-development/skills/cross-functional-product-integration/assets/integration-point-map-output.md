# Output format: integration point map (draft for the person)

Short mode: 450 words maximum, counted without the calls list and tables' source column. Before handing over, count the words. If over 450, cut in this order until under: context paragraphs, repeated row ids in prose, secondary rules, rows not tied to the person's question. Never cut a gap, a stop or the record line. Refusals follow the same 450-word cap.

## Short mode (default for a direct question)

1. **Answer:** the decision the map serves (person's words), the number of integration points, how many have a gap, and which anchor carries the most points.
2. **Integration points:** table Work product · Sender (function, person named) · Receiver (function, person named) · Blocked decision · Anchor and rows, or "the person's" · Gaps.
3. **Review attendees** (only if the person named a review): the functions the person listed, beside sending or receiving functions not on the list, as differences for the person to resolve (PL1).
4. **Stops:** anything routed, by pack and skill (for example `dh-regulatory-and-quality` design-controls-and-risk-management, `dh-regulatory-and-quality` regulatory-pathway-and-classification), labeled "draft for the owner".
5. **Record:** "Integration map draft. AI-assisted." Clears it: [the person named, in their words, or owner not named]. The record is built with `verify.build_record` once that named person clears it; until then, uncleared draft. This is the last line of the answer body.
6. **Calls made** (after the record line): list (or "none; the person's material and the sourced rows only").
