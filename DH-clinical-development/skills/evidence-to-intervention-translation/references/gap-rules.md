# Gap rules

A gap is information. Each reason for a gap leads to a different next step, so name the reason.

## Rule facts

| Class | When | How to word it | Next step |
|---|---|---|---|
| Sourced | A research row states it | The fact plus the row id ("decision rules link options and tailoring variables, TM82") | None |
| Published method | The row is [PAPER] | "JITAI decision rule (TM82), DOI 10.1007/s12160-016-9830-8" | Cite the DOI |
| Abstract only | BCTTv1 (TM51 to TM53), Bellg (TM99), Balshem and Santesso (ES-199 to ES-201) | "BCTTv1, abstract only (TM51)" | Do not rely on content not in the abstract |
| Summarizer read [WF] | GRADE EtD Part 1 (TM107, TM108), IDEAL-D 2016 (PL121) | "read through WebFetch only (TM107)" | Use Moberg 2018 (TM109 to TM113) for the criteria |
| Nonbinding guidance | FDA guidance such as CFL | "FDA recommends (nonbinding guidance, PC-US-23)" | Do not present as law |
| Binding for a named device type | 21 CFR special controls | "882.5801 special control (TM120); applies to that device type" | Applicability is for the owner the person names for regulatory status, or owner not named |
| Not in the sources | BCTTv1 technique list, Bellg strategies, newer De Novo summaries (882.5804, 880.5735, 886.5500 devices), Somryst and Rejoyn clearances | "Not in this skill's sources [GAP]" | The owner the person names, or owner not named |

## Evidence facts

| Situation | How to word it |
|---|---|
| No passage read for a claim | "No passage read [GAP]"; the claim is not sourced |
| Verify returns "supported" | Reported as support only when the passage was read and says the same thing, in the same direction (N3) |
| Verify rates a source inadmissible | "Verify could not admit this source (C1); passage quoted from row TMxx" |
| Library design or level label | "Library label `rct`, CEBM level 2 (from the design tag); not GRADE certainty" (N8) |
| `trial_ids` empty | "Registry id not on the record [GAP]; checked with find_trial" |
| Certainty not rated | "Certainty not rated [GAP]; literature-and-real-world-evidence-review" |
| Abstract only, full text open | Read the full text before marking a field [GAP]; say "abstract only" when the full text is not open |

## The person's facts

| Situation | How to word it |
|---|---|
| Intended use or population not stated | "Intended use not stated [GAP]"; widening cannot be tested until it is |
| Device status unknown | "Device status not stated [GAP]; the owner the person names for regulatory status, or owner not named" |
| Dose not chosen | "Planned dose not stated [GAP]"; the tested dose is shown beside it |
| No owner named | "Owner not named"; ask. Never suggest a job title |
| Mechanism stated without a source | Recorded as the person's hypothesis, labeled; never filled |

## Never

- Never call a component, feature or product effective, validated or evidence-based on a library label or a Verify status.
- Never fill a population, dose, effect size, threshold or certainty from memory.
- Never treat "not studied" as "shown not to help", or the reverse.
