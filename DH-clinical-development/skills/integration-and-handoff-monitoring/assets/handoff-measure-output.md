# Output format: handoff measure (the person's rule, dated)

Short mode: 450 words maximum, counted without the calls list and tables' source column. Before handing over, count the words. If over 450, cut in this order until under: context paragraphs, repeated row ids in prose, secondary rules, rows not tied to the person's question. Never cut a gap, a stop or the record line. Refusals follow the same 450-word cap.

## Short mode (default for a direct question)

1. **Answer:** the received rule in the person's words (or the default offered, labeled "framework default, not a sourced standard"), the period, what "late" means, and what is still to confirm.
2. **Measure:** table Element · The person's wording · Pattern behind it (labeled) · Rows.
   Elements: received rule; evidence of receipt; handoffs scored; period; carried-in items; late; categories; CTQ marks (CV29); target (or "no target set").
3. **Not set yet:** each element the person has not confirmed, `[GAP]`.
4. **Record:** "Handoff measure, version dated [date]. AI-assisted." Clears it: [the person named, in their words, or owner not named]. The record is built with `verify.build_record` once that named person clears it; until then, uncleared draft. This is the last line of the answer body.
5. **Calls made** (after the record line): list (or "none").
