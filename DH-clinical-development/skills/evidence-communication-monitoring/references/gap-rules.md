# Gap rules

A gap is information, not an apology. Each reason leads to a different next step. When a source is open access, read the full text before marking a field `[GAP]` from an abstract.

| Class | When | How to word it | Next step for the person |
|---|---|---|---|
| Person's rule not set | Pass rule, threshold, owner, communications in scope | "No pass rule for disclosure timing: no verdict `[GAP]`." | Ask once; offer the rule shapes in B1 as "proposed". |
| Regime not confirmed | US applicable clinical trial status, EU CTR scope, WHO signatory, ICMJE journal | "EU CTR scope not confirmed: EU clock not computed `[GAP]`." | Ask; route to the owner the person names for regulatory status, or owner not named. |
| Date not supplied or ambiguous | First consent, first enrollment, primary completion, end of trial, posting date; a registry field whose meaning differs | "Only the registry start date was given; first consent is not the same field `[GAP]`." | Ask for the date, or for confirmation that the registry field is the one meant. |
| Passage missing | A statement with no results passage | "No passage for 'symptoms halved': not checkable as worded `[GAP]`." | Ask for the paper or the A1 statement. |
| Rating missing | Certainty word with no rating behind it | "Certainty claimed 'high'; no rating given `[GAP]`." | Ask who rated it. |
| Library cannot answer | No dates from `find_trial`, non-ClinicalTrials.gov registry, empty search, Verify status without a reading | "The library returns no dates for NCT...; dates from the person's registry record." | Use the registry record. |
| Not sourced | Penalties, EU CTR Annex IV and V content, pediatric timelines, impact measures | "Not sourced here `[GAP]`." | Name the text to read, or treat it as the person's measure. |

## Never

- Never turn an empty registry link or search into "unregistered" or "unpublished".
- Never call a communication accurate because no flag was raised.
- Never estimate a missing date, effect or rating.
