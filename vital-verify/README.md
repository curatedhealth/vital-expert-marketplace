# VITAL Verify

Install **VITAL Verify** from `curatedhealth/vital-expert-marketplace`, then paste the Verify key if you have one. The key is not in this pack.

The connector is `https://mcp.vital.expert/api/mcp/verify`. Do not add a second connector.

Seven skills: source grading, claim decomposition, support decision, currency check, honesty, escalation, and the record. Pick the one that matches the question. A missing field stays missing. A record with no human name is a draft.

For everyday life-sciences drafting against the TRUSTED standard (Tangible, Rule-compliant, Unbiased, Safe, True, Ethical, Defensible), install **vital-trusted** from the same marketplace. TRUSTED is the free method layer; its Prove skills call this connector when the key is present. Method skills are consolidating into TRUSTED; this pack remains the connector plus these seven skills for one release.
