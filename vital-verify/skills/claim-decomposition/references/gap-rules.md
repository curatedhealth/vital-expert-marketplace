# Gap rules

Classify every miss before you write it. Never turn an absent row into a fact.

| Class | Meaning here | How to word it |
|---|---|---|
| found | The connector returned the field or the passage states the detail | Quote it |
| field missing | The source was read and one field is empty | Name the field. Leave it empty |
| covered but absent | An admissible source was checked and does not state the detail | Say the passage does not state it |
| not covered | No admissible source was available | Say no admissible source was available |

Do not write "false" from an empty field. Do not fill a field from memory. The four class names are the pack standard as of 19 October 2026. The mapping below is this task's.

- A sentence you cannot find in the text is not covered. Do not add it.
- A year inside a sentence is found as part of that sentence, not a second claim, unless the year is the only new point.
