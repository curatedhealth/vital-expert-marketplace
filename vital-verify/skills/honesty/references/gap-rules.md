# Gap rules

Classify every miss. Never turn an absent row into a fact.

| Class | How to word it |
|---|---|
| found | Quote what the connector returned |
| field missing | Name the empty field and leave it empty |
| covered but absent | Say the checked source does not state it |
| not covered | Say no admissible source was available |

The four class names are the pack standard as of 19 October 2026.

- found: the passage states the figure, name, or quotation.
- field missing: the passage is on the right topic and lacks the figure. Drop the figure. Keep only the words the passage states.
- covered but absent: the source was checked and the boast is not in it. Cut the sentence.
- not covered: unverifiable. Cut the sentence. Do not write a plausible stand-in.
