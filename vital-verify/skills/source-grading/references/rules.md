# Primary rules this skill applies

Last reviewed: 20 October 2026.

| Id | Rule | Primary source | Status |
|---|---|---|---|
| R1 | Promotional claims must be capable of substantiation from appropriate evidence. | IFPMA 2019 §4.3; ABPI 2024 6.1–6.2 | Confirmed 20 October 2026 (via shared Prove sources) |
| R2 | Tier order and six provenance fields are decided by `mcps/verify/tiers.py` (`tier_for`) and score axes by `source_score.py`. The skill states the rules; the code decides. | Verify service, 19 October 2026 | Confirmed from code paths named in `tiers-and-score.md` |
| R3 | Never assert peer review you cannot show. "Peer reviewed" needs a journal and published version, or a statement in the source. | Good practice aligned with TRUSTED source-assessment TR-H1/H2 | `[CHECK]` |
| R4 | Never say a source is good, bad, reliable or acceptable. Say what it can support for which reader. | TRUSTED Prove / Verify method (VR-H3) | Confirmed as pack hard rule |

`[CHECK]` External typology (e.g. CEBM levels) is not required for this skill's tier labels.
