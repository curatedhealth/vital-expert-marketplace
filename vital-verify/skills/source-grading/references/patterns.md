# Failure patterns

Teaching only (VR-H2).

**S1 Invented publisher.** URL looks official; assistant fills publisher from memory.
After: leave the field empty; name the gap. (VR-H1)

**S2 Simulated gold.** No key; result still says "gold".
After: method-only / not tool-checked; never invent a tier. (VR-H4)

**S3 Bronze promoted.** Press release raised to silver because it is from a company site.
After: keep bronze; hand to support-decision for at most partial. (R2)

**S4 Good/bad verdict.** "This is a high-quality source."
After: say what it can carry for this reader. (R4, VR-H3)

**S5 Model text as source.** Assistant cites its own paragraph.
After: inadmissible; type model. (R2)
