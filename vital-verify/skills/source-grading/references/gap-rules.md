# Gap rules

Classify every miss before you write it. Never turn an absent row into a fact.

| Class | Meaning here | How to word it |
|---|---|---|
| found | The connector returned the field or the passage states the detail | Quote it |
| field missing | The source was read and one provenance field is empty | Name the field. Leave it empty |
| covered but absent | An admissible source was checked and does not state the detail | Say the passage does not state it |
| not covered | No admissible source was available | Say no admissible source was available |

Do not write "false," "not reimbursed," or "outdated" from an empty field. Do not fill a field from memory. Source of the classes: the skill-pack gap rule, applied to Verify statuses as of 19 October 2026. The four names are the pack standard. The mapping onto Verify statuses is in the task that uses them.

Mapping for a grade:

- A date the page did not carry is field missing.
- A URL the fetcher could not read is not covered.
- A model paragraph is not covered. It is not a source with a missing field.
