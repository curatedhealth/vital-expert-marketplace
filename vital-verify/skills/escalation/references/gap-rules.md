# Gap rules

Classify every miss. Never turn an absent row into a fact.

| Class | How to word it |
|---|---|
| found | Quote what the connector returned |
| field missing | Name the empty field and leave it empty |
| covered but absent | Say the checked source does not state it |
| not covered | Say no admissible source was available |

The four class names are the pack standard as of 19 October 2026.

- found: the passage and the locator are in the packet.
- field missing: a locator was not returned. Say so. Do not invent a page number.
- covered but absent: status unsupported or contradicted. The question asks the person what to do with the sentence.
- not covered: unverifiable. The question asks which source to fetch.
