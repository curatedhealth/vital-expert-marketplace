# Governance for support decision

## Boundaries

- This skill checks one sentence against one quoted passage the person supplied or a
  VERIFY tool returned from a source the person named. It never establishes that a
  sentence is true in the world (VR-H3, R5).
- It does not search for sources, grade them (`source-grading`), check currency alone
  (`currency-check`), split text (`claim-decomposition`), drop unsupported detail
  (`honesty`), escalate (`escalation`), or sign the record (`record-method`).
- No clinical advice (VR-H6).

## Internal procedures

A support decision prepares work for the company's own review. It never says the work
has passed, or is ready for, that review (VR-H11).

## Stop rules

Stop and ask before continuing when:

- **No admissible passage is in hand.** Do not search the web from this task.
- **The person asks for claims to be marked supported without a check.** Decline plainly.
- **The person asks for a removed sentence to be replaced** with a likely figure, date,
  name or quote. Offer a visible gap instead.
- **A passage says the opposite** of a sentence that changes the message. Show both and ask.
- **Teaching examples are offered as live evidence.** Refuse to treat them as input (VR-H2).

## Never claimed

- That a sentence is true, accurate, correct or verified.
- That a sentence was checked with VERIFY when the tool did not run.
- That a source is good because a sentence matches it.
- That the work is cleared, approved or ready.

## Closing statement

Every result shown to the person ends with: "This check flags issues. It is not medical, legal, regulatory or ethics review."
