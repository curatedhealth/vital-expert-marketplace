# Gap rules

Classify every miss before you write it. Never turn an absent row into a fact.

| Class | Meaning here | How to word it |
|---|---|---|
| found | The connector returned the field or the passage states the detail | Quote it |
| field missing | The source was read and one field is empty | Name the field. Leave it empty |
| covered but absent | An admissible source was checked and does not state the detail | Say the passage does not state it |
| not covered | No admissible source was available | Say no admissible source was available |

Do not write "false" from an empty field. The four class names are the pack standard as of 19 October 2026.

- found: status supported, or the supported half of partial.
- field missing: the passage supports the sentence except for a figure or a name it does not contain. Status partial.
- covered but absent: admissible sources were checked and none support the sentence. Status unsupported. If one states the opposite, contradicted.
- not covered: unverifiable. The sentence stays out of the answer.
