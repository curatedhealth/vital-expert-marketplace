# Gap rules

A gap is information. The person needs to know why something is missing, because each reason leads to a different next step.

## The person's data

| Situation | How to word it | Next step |
|---|---|---|
| No rule for a measure | "Counted: N. No rule set `[GAP]`; not judged." | Ask for the rule. |
| No record for a measure | "Not measurable `[GAP]`: no record of X." Name who would hold it. | Ask the data owner. |
| Partner report not tied to a buyer | "Partner-reported, not tied to a buyer in your record: not counted." | Compare lists with the partner. |
| Evidence of a duty not given | "Not shown." Never "breached". | Ask the owner for the evidence. |
| Different periods or units | Keep them apart and name each. | Ask. |

## Rules and public signals

| Class | How to word it |
|---|---|
| Sourced rule | The rule with its CP row. |
| Rule from guidance, not the standard | "NHS England guidance states...; the standard's own text was not read `[GAP]`." |
| Not sourced | "Not in the sourced rules `[GAP]`; this needs your legal owner." |
| Library log shows no change | "No change recorded in the library's log since DATE (log started 12 October 2026)." Never "no change". |
| Source not loaded | "The library holds no data from SOURCE `[GAP]`." |
| Tool label without a basis | "The tool had nothing to compare against; its label is not a finding." |

## Never

- Never turn a gap into "failed", "breached", "non-compliant" or "fine".
- Never fill a gap from memory or a passage without a source URL.
