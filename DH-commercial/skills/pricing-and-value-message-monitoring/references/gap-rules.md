# Gap rules

A gap is information, not an apology. Each reason leads to a different next step.

| Class | When | How to word it | Next step for the person |
|---|---|---|---|
| Person's rule not set | Corridor, deal set, realized-price rule, pass rule, owner | "Corridor not given: deals cannot be positioned `[GAP]`." | Ask once; offer the old checklist as "proposed". |
| Data not supplied | Deal values, units, list prices, contract ids, message results | "Units missing for 3 deals: realized unit price not computed `[GAP]`." | Ask for the field; never estimate it. |
| Intended use not stated | No label or authorization text for the market | "Intended use for the EU not stated: flags are provisional `[GAP]`." | Point to the regulatory owner or dh-regulatory-strategy. |
| Passage missing | A numeric or efficacy claim with no source passage | "No passage for '45 minutes longer': unsupported as worded `[GAP]`." | Ask for the study or document. |
| Library cannot answer | No authorization record matched, intended purpose not stored, tool error | "The library holds no intended purpose for this record; its claim labels are not used." | Rely on the person's label text. |
| Not sourced | A rule the research files do not hold (amended UCPD text, German UWG, MHRA device advertising rules) | "Not sourced here `[GAP]`." | Name the text to read; never fill from memory. |

## Never

- Never turn "no authorization on file" in the library into "unauthorized" or "not a device".
- Never call a claim compliant because no flag was raised. "No flag" means no sourced rule in these references was matched.
- Never estimate a missing deal value, unit count or result.
