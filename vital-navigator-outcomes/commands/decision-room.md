# Decision Room (short session)

Product UI / select-and-score screen is a **platform surface** (not a new CF04 skill). This command is the offline facilitation path.

## When to use
Owner wants a 45–90 minute decision session without walking every spine skill file. Still non-gate vocabulary.

## Flow
1. `route-the-entry` — refuse Launch/READY/DD absorption.
2. Frame in one pass (`frame-the-decision`) — decision of intent + options including do nothing / handle internally.
3. **Select-and-score** — people enter criteria weights and 1–10 scores; attach worksheet; run offline compute scripts (or `methods_nav_compute` if live).
4. Optional `run-weight-sensitivity` — show instability; do not choose.
5. Challenge — premortem + dissent by name (Companion or facilitation list).
6. Integrity Lite if IC-bound: ground → cut → verify posture → lock exhibits.
7. `compile-board-pack` or `close-the-decision` — Proceed / Investigate first / Handle it internally; signed=false.

## Hard don'ts
- No assistant scores, choices, or signatures.
- No MLR / Launch Pass language.
- No inventing figures to finish on time — `[GAP]` and Investigate first.
