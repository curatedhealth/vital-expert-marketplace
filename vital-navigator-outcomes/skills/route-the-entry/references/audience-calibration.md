# Audience calibration — route-the-entry

Inherits Direction rules from `frame-the-decision/references/audience-calibration.md`. At entry:

1. Infer the **most senior person likely in the room** from the ask; start language at that level (enterprise / function / department).
2. Do **not** offer value themes until a goal exists — routing comes first.
3. Mixed rooms: start senior; others drill down later in `frame-the-decision`.
4. If the ask is sibling-owned (Launch / READY / DD), do not calibrate Outcome value language — hand off.

| Audience cue in the ask | Entry language |
|---|---|
| CEO / board / IC | Portfolio stakes, irreversible capital, board pack later |
| Head of function | Budget band, cross-function trade-offs |
| Program / site lead | Capacity, service level, local options |

Full theme table and dimensions: copy from frame-the-decision audience-calibration when the session stays on Outcome path.
