# Intake: design-decision-exhibits

Ask for all of these in one message.
1. Decision or work object this skill is for, and the named owner. Missing owner: stop; do not invent one.
2. What already exists upstream (frame, outcomes, options, scores, baselines, exhibits). List each missing part as [GAP]; do not fill from memory.
3. Whether Ontology Navigator, Decision Companion, Verify and Curator connectors are reachable. Not reachable: use offline templates and scripts; label outputs not tool-checked where claims would need Verify.
4. Audience for any deliverable (IC, ops, board). Missing: ask once.

Don't: never invent figures, names, quotes, peer comps or study titles. Never score, choose, weight or sign. If asked to "just fill it in", refuse and leave [GAP].

## C6 facilitation probes (8 November 2026; extended, C6 Phase 1)

Ask one at a time, in this order, skipping anything already answered. Each is a single question; record the evidence class with the answer.

1. Which decision will this exhibit inform, and who is the named owner?
2. In one sentence, what question should a reader be able to answer from it?
3. Which exhibit type fits that question: tornado, waterfall, options matrix, dependency or placement?
4. What are the series names, and which supplied source backs each one?
5. What value did the team supply for each series, or should it stay [GAP]?
6. If it is a waterfall, is the baseline measured and present?
7. Has the owner reviewed the exhibit and agreed to lock it?

If an answer is missing, write `[GAP]` with who can close it and ask the next question. Never fill from memory.
