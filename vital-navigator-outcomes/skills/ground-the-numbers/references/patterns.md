# Patterns: ground-the-numbers

Teaching shapes only — never copy figures into a live answer.

## Fabrication patterns (refuse)
| Id | Pattern | Repair |
|---|---|---|
| F1 | “Industry average ROI is X×” with no source | [GAP] or drop |
| F2 | Peer adoption % from model memory | [GAP]; ask for named study |
| F3 | Backcast baseline invented for track-value-realized | rebuild-baselines; never invent |
| F4 | “Analysts say…” unnamed authority | Not a source; remove |
| F5 | Quote attributed without notes | Remove or [GAP] |
| F6 | Cause claimed (“because of the AI roll-out”) not in material | Remove cause |
| F7 | Superlative (“largest”, “only”, “first”) unsupported | Soften or [GAP] |

## Number consistency patterns
| Id | Pattern | Repair |
|---|---|---|
| N1 | Relative uplift without absolute | Add absolute from same base or [GAP] |
| N2 | Percent vs percentage points conflated | Relabel |
| N3 | Midpoint invented for a range | Keep low/mid/high only if team entered mid |
| N4 | Currency converted without factor | [GAP] FX factor |
