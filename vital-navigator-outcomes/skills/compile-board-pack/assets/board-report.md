# Board report (Outcome Navigator)

## How to read this pack (8 client sections <-> 10 shared parts)

Client-facing close uses **eight sections + annex** (`close-the-decision` / playbook).
The shared non-gate substrate uses **ten parts** (`references/decision-record-standard.md`). Map once; never show part numbers to the reader.

| Client section (8) | Shared parts (10) |
|---|---|
| 1. Decision | 1 Identity + 2 Frame + 3 Decision rights |
| 2. Value at stake | (from size) + prediction band in 6 |
| 3. Outcome priorities | (from prioritize) feeding 5 |
| 4. Capability and gap register | (from readiness / leaks) feeding 5-7 |
| 5. Options considered | 4 Options + 5 Criteria and evidence |
| 6. Recommendation and route | 6 Choice, rationale, prediction |
| 7. Assumptions and risks | 7 Active assumptions |
| 8. Dissent | 8 Challenge (+ 9 Journal human-only; 10 Follow-up later) |
| Annex | Sources, gaps, prepared-with / clearer |

Result vocabulary only: **Proceed** / **Investigate first** / **Handle it internally**. Never Launch Pass/Hold/Escalate. Never MLR.
