# Gap rules

A gap is information. Say why something is missing, because each reason leads to a different next step.

| Situation | How to word it | Next step |
|---|---|---|
| A design or reporting rule is not in the sourced rows | "Not sourced `[GAP]`" with what is missing (for example STROBE item wording, Berger recommendation 4, the German value-set expectation for DiGA) | Name the primary source a person would read |
| The library found no registration link | "No ClinicalTrials.gov link found by the library; registration not confirmed `[GAP]`" | Ask for the registry and id |
| The registry is one the library does not search (HMA-EMA Catalogue, ENCePP, PROSPERO) | "The library does not search this registry `[GAP]`" | Ask for the record |
| A date in the execution log is missing | "Not dated `[GAP]`: order cannot be shown" | Ask who holds the dated document |
| First outcome access is not dated | "First outcome access not dated `[GAP]`; prespecification cannot be shown" | This blocks a HETE label; ask first |
| A design label from the library disagrees with the paper | "Library label X; the paper's methods describe Y" | Use the paper; note the label |
| The person has not chosen (estimand strategy, comparator, value set, market) | "Your choice, not made yet" | Lay out the options with rows |
| Only the abstract was read | Open-access source: read the full text first; `[GAP]` only if the full text also lacks it. Paywalled: "Abstract only; not checkable `[GAP]`" | Ask for the full text |
| The person has not named an owner | "Owner not named" | Ask; never assign |
| No usable-result rule set | "No rule set: factual summary only" | No verdict |

## Never

- Never turn "no registration found" into "not registered", or "not in the library" into "no evidence exists".
- Never fill a gap from memory, from a library passage without a source URL, or from a design label you have not checked against the paper.
- Never date a document the person has not dated.
