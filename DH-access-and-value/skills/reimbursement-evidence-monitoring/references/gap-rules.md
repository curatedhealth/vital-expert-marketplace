# Gap rules

A gap is information. Name its reason, because each reason leads to a different next step.

## For a decision (A1)

| Class | When | How to word it | Next step |
|---|---|---|---|
| Read | The decision text was read and is quoted | "[Section], read DATE: '[verbatim]'" | None |
| `[GAP]` not read | The library row exists but the document was not read | "`[GAP]`: decision text not read; the library holds the page header only" | Read the page or ask for the document |
| `[GAP]` not published | The body does not publish it (re-evaluation outcomes, narrowed DiGA list, individual reports not sourced) | "`[GAP]`: not published by [body] as of DATE ([row])" | None; do not infer |
| `[GAP]` not in the library | The scheme holds no rows (FR_LPPR, UK_NICE_NHAP) | "`[GAP]`: the library holds no rows for [scheme] (DATE)" | Check the body's site |
| Stored status at odds with the title | An early-use title stored as permanent | "Stored as [status]; the title says early use; check the guidance" | Read the guidance |

## For an evidence obligation (A2)

| Class | When | Wording |
|---|---|---|
| Collected | The person's records show the outcome is being collected | "Collected: [outcome], [source]" |
| Not collected | Asked by the body; the person's records do not show it | "Not shown in the records supplied" |
| `[GAP]` | The person has not said | "`[GAP]`: collection status not stated" |
| Window | A stated period or the PMG48 default | "Window: [period], from [date], [source or row]; as of DATE, [n] days passed / remaining" |

## For a methods change (A2)

"Applies to [topic] because [date rule, row]" or "does not apply because [reason, row]" or "`[GAP]`: topic date not given". Never "the model is out of date": say what the change touches; the owner decides whether to update.

## For an outcome review (B1)

Each rule: met, missed, or not measurable `[GAP]`, with the fact behind it. A body without the person's rules gets a factual summary and no verdict.

## Never

- Never paraphrase a committee statement into a stronger one ("could be cost effective" is not "cost-effective").
- Never forecast a re-evaluation, a withdrawal or a listing.
- Never treat a library absence as a decision, or a comparable's outcome as the person's odds.
- Never fill a gap from memory.
