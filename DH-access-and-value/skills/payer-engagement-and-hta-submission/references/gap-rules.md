# Gap rules

A gap is information. The person needs to know why something is missing, because each reason leads to a different next step.

## For a requirement against the person's evidence (A1)

| Class | When | How to word it | Next step |
|---|---|---|---|
| Shown | The person's document or a checked passage shows it | "Shown: [what], [document, section]" | None |
| Not shown | The requirement applies and nothing the person supplied shows it | "Not shown in the material supplied" | Ask for the document, or plan the evidence |
| `[GAP]` record silent | The library record cannot answer (country, registration, comparator, endpoints) | "`[GAP]`: the record does not state [field]; check the paper, section X" | Person supplies the section |
| `[GAP]` rule not sourced | The references do not hold the body's rule | "`[GAP]`: rule not in the sourced references (read 19 October 2026); check [authority]" | Check the authority |
| Not applicable | The rule's condition does not hold (for example trial-listing rules for a class IIb DiGA) | "Not applicable: [reason, row]" | None |

## For a checklist item (A2)

Present, missing, or `[GAP]` (the person has not said). Never "complete" for the whole file unless every item is present, and even then say "complete against the sourced checklist of [date]", not "ready".

## For a claim (B1)

| Verify status | Your reading | Usable in the narrative? |
|---|---|---|
| supported, and the passage states the result in the same direction | Checked | Yes, with source and passage |
| supported, but the passage is not a result or says something else | Not checked (overlap only) | No |
| any other status | As returned | No, until resolved |
| no source | Unverified | No |

## Never

- Never turn "not shown" into "the product does not meet the requirement".
- Never treat a library absence (no precedent, no guidance passage) as a rule.
- Never fill a gap from memory, from a guidance passage without a source URL, or from a Verify status alone.
