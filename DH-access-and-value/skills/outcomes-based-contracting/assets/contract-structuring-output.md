# Output format: contract structuring (term sheet draft)

## Short mode (default for a direct question)

**Short mode: 450 words maximum, counted without tables' source column; cut in this order: context paragraphs, secondary rules, full-mode sections; offer the full version in one line.** The calls list is not counted; aim for at least 250 words. No full payment table or full term list in short mode.

1. **Design test:** Uncertainty named? Data source exists? Value of information exceeds cost? One line each: pass, fail or open, with the fact.
2. **Terms set:** the terms the person has given, one line each.
3. **Terms open:** each with the question that settles it.
4. **Inconsistencies:** at most three.
5. **Record:** "Term sheet draft for the owner. Every term stops for NAME. Uncleared." or the clearer's name.
