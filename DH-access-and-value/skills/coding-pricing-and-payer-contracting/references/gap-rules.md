# Gap rules

A gap is information: each reason leads to a different next step.

| Class | When | How to word it | Next step |
|---|---|---|---|
| Stored | The library holds the code or listing with an amount. | Code, amount, setting, source, retrieval date. | Confirm at CMS, BfArM or Légifrance before external use. |
| Stored, field empty | Row exists; `price` empty but the passage states an amount, or no amount at all. | "Amount stated in the stored passage; price field empty" or "contractor priced, no national amount". | Read the passage; for contractor pricing, the MAC. |
| Not stored, sourced | The library has no row, but a research row states the fact (99445, RTM codes, EBM 86700, ACCESS). | Cite the research row id. | None beyond re-checking the source. |
| Not sourced | Neither library nor research rows hold it (national RPM dollar amounts outside the stored codes, LATM fee amounts, CEPS clauses, commercial payers). | `[GAP]` with the row in "Not sourced" that says so. | Name the authority to read. |
| Person's input missing | Regulatory class, FDA classification, indication, objectives, walk-away. | `[GAP]: needed from you`. | Ask once. |

## Proposed rules

A proposed rule is not a gap and not a fact: write "proposed on DATE, final rule not published as of the read date", with its row (US23 to US28).

## Never

- Never read absence from the library as "no code pays for this".
- Never fill a dollar or euro amount from memory or secondary sources (coding file Not sourced 1).
- Never turn a comparator's price, a corridor, or a model ceiling into the person's price.
