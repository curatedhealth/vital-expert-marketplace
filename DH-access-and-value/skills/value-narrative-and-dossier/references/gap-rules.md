# Gap rules

A gap is information, not an apology. Each kind of gap leads to a different next step.

| Class | When | How to word it | Next step for the person |
|---|---|---|---|
| Person's decision not yet made | An audience, a claim to carry, a certainty rating, an owner, a use of the narrative, a model input | "Certainty for ISI at 10 weeks: not yet rated `[GAP]`." | Ask once. Never fill it; if asked for a proposal, label it "proposed". |
| No passage | A value claim with no DOI, document or passage, or with a passage that states only aims or design | "Sleep duration benefit: no supporting passage `[GAP]`; held out of the narrative." | Supply the document, or drop the claim. |
| Passage does not match | The passage is about another population, comparator, outcome or time point, or states the opposite | "Read in a different population (pregnant women); not carried for adults." | Narrow the claim to what the passage states, or find the study that matches. |
| Not sourced | A rule or dossier section no row holds (AMCP 6.0 final text, DiGA dossier content, HAS device economics) | "AMCP 6.0 final section list: not read here `[GAP]`." | Name the document to read; do not fill from memory. |
| Library gap | The library holds no passage or record (guidance store empty, `trial_ids` empty) | "Trial registration: not in the library record `[GAP]`; the abstract names NCT02805998." | Read the paper or registry directly. |
| Tool failed | HTTP 422 or 503 | "Budget impact tool unavailable (HTTP 422, 19 October 2026)." | Arithmetic in the conversation on the person's numbers, labeled hypothesis, or point to DH-01.07.2. |
| Catalogue job closed | `value-dossier` is design-partner only | "The library's dossier job is open to design partners only; built by direct calls." | None; task A2 runs. |

Open access: When a source is open access, read the full text before marking any field `[GAP]` from the abstract or the library excerpt.

## Never

- Never fill a missing passage, certainty, threshold or dossier section from memory.
- Never turn "no passage found" into "the product does not work", or a passage into "proves".
- Never treat a tool's grade or design label as a certainty rating.
