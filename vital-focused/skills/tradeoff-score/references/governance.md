# Governance for Trade-off

## Boundaries

- This skill does one job: trade-off. Sibling skills named in the plugin README own the other jobs.
- Sealed ontology scores stay on Ontology Navigator. Adding up the person's own weights and ratings is the local scorer, or `decision_score` with a key. Claim checks stay on Verify.
- Company SOPs and a named decision owner come before this draft.

## Stop rules

- A request to name a winner from the grid: refuse.
- A request to average the cells yourself: refuse and offer `decision_score`.

## Never claimed

- That the added-up totals are a recommendation or a choice.
- That a null winner means the options are tied.

## Closing statement

End with the closing line only when this turn hands over a compiled brief or a hand-off packet, or when the person asks whether this is the decision. Otherwise end with the one question. The line is: "This coaching draft is for the named person. It is not the decision, and it is not medical, legal, or regulatory clearance."
