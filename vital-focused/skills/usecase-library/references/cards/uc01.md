# UC01: Competitive product launch response

> **Teaching material, never input (DC-H2).** Gold use-case card from the FOCUSED content pack. Never copy its choice onto a live session.

- Decision type: response_customer
- Rigor: decide_quickly

## Beats

1. State the rival move in one sentence and the date it becomes visible to customers.

2. Name the consequence of waiting one cycle.

3. Force a do-nothing option and a do-it-internally option before any new program.

4. Gather only the facts that would change the response this week.

5. The person states the response. The companion does not pick it.
