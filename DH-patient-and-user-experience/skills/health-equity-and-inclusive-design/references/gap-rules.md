# Gap rules

A gap is information. Each reason for a gap leads to a different next step, so name the reason.

## Requirement facts

| Class | When | How to word it | Next step |
|---|---|---|---|
| Sourced | A row states it. | The fact plus the row id ("92.210(b) and (c) apply within 300 days of 5 July 2024, PE-115"). | None. |
| Applicability not sourced | Whether the person or their customer is a Section 1557 covered entity. | "Covered-entity status is not in this skill's sources `[GAP]`; your legal owner decides." | Ask the legal owner. |
| Summarizer read [WF] | Core20PLUS5 (PE-127 to PE-129). | "Per NHS England's Core20PLUS5 page, read through a summarizing tool [WF]." | Re-check the page before quoting outside the conversation. |
| Draft, status unsettled | Diversity action plan guidance (PE-40, PE-41). | "Draft, restored under a court order; FDA lists it as draft on 19 October 2026. Reading in the research file: the statutory duty is not yet triggered while no final guidance exists. Not an FDA statement." | Regulatory owner. |
| Standing unclear | CMS Framework for Health Equity (PE-118, PE-119). | "Framework document; its current standing as CMS policy is not established in the research." | None; cite as a framework. |
| Not in the research | EU or UK equality duties beyond the rows, litigation stays on Section 1557, a small-cell threshold, any change type without a row. | "Not in this skill's sources `[GAP]`." | Legal owner, or the person's own rule. |
| Industry code | EFPIA, ABPI rows. | "[INDUSTRY] code, not law." | Compliance owner. |

## The person's facts

| Situation | How to word it |
|---|---|
| Subgroups not named | Show the frames as options (equity-frames.md); ask which they adopt. Do not pick. |
| Product steps not described | Ask for the steps from first contact to the outcome; without them, exclusion cannot be placed at a step. |
| No counts for a subgroup | "Not measured `[GAP]`"; name the record that would hold it and route to A2. |
| Counts with "not recorded" values | Report the share not recorded; never redistribute it across groups. |
| No small-cell threshold | Ask for it; do not run the script without it. |
| No reference group | Show rates only; no differences or ratios. |
| No owner | Use the owner or role the person names, in their words. Only if they named none, write "owner not named" and ask. Never suggest a job title. |
| No version | "Version not set"; ask. |
| No scores for B1 | No ranking. Lay out the facts per option and ask the person to score. |

## Library facts

| Situation | How to word it |
|---|---|
| Guidance store returns nothing (Section 1557, diversity action plan) | Use the sourced rows; do not say the topic has no guidance. |
| Literature record design label | Read the record; the label can be wrong (tools.md). |
| `check_claim` "supported" | Accept only if you read the passage and it states the claim in the same direction. |

## Never

- Never fill a rate, count, requirement, owner, score or version from memory.
- Never treat a missing row as "not required" or a missing group as "not affected".
