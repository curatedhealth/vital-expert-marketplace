# Gap rules

A gap is information. Each reason for a gap leads to a different next step, so name the reason.

## Definition and method facts

| Class | When | How to word it | Next step |
|---|---|---|---|
| Sourced | A research row states it. | The fact plus the row id (for example "reach on a valid denominator, CS27"). | None. |
| Abstract only | The row was read from an abstract (Yardley 2016, PAM-13 2005, RE-AIM 1999). | Say "abstract only" once. | Read the full text before relying on detail. |
| Summarizer read | The row is marked [WF]. | Say the rule rests on a summarizer's reading. | Re-check against the page before external use. |
| Licensed or not public | PAM level cut points and scoring (CS research "Not sourced"); GAD-7 cut points. | "PAM level cut points are not in this skill's sources `[GAP]`; PAM scoring is licensed." | The person's license holder or instrument documentation. |
| Not in the sources | A benchmark, a "good" retention rate, an industry average engagement figure. | "No sourced benchmark `[GAP]`; the threshold is yours." | The person sets it, or names a published program to read as context. |
| Industry code | A row marked [INDUSTRY]. | Say it is a code, not law. | None. |

## The person's facts

| Situation | How to word it |
|---|---|
| No decision named for a KPI | "Decision not named"; ask. A KPI with no decision is not placed on a dashboard. |
| No denominator | "No denominator: a count, not a rate"; ask which population. |
| Denominator is volunteers, downloads or sign-ups for a reach KPI | Name it as such and offer the valid denominator (all eligible, CS27); the person chooses. |
| No period | "Period not stated"; the KPI is not computed. |
| No rule for "stopped" | Ask for the number of days without use; no default is applied. |
| No dose for effective engagement | Ask; PE-104 defines the idea, not the dose. |
| No eligible list | Reach and penetration are not computed; say which list would hold it (referral list, panel, registry). |
| No threshold | Report the number; no verdict. |
| No owner named | Use the owner or role the person names, in their words. Only if they named none, write "owner not named" and ask. Never suggest a job title. |
| No audience named for a dashboard | Ask; do not build one dashboard for every audience. |
| Data described but not shared | "Described, not computed"; no figure is produced. |

## Data problems in the event file

| Situation | How to word it |
|---|---|
| Blank or invalid dates | Count them; exclude them; never impute. |
| Events after the as-of date | Count and ignore them. |
| Use events before a person's start | Count and ignore them; ask whether the start event is right. |
| Use events with no start event | Count the people; exclude them; ask. |
| A month with no events | "No events recorded in MONTH: a feed outage or a real stop cannot be told apart from this file." |

## Library facts

| Situation | How to word it |
|---|---|
| Verify unreachable | "Verify was not reached; cited from the reference row." |
| Literature search returns nothing relevant | "No record found by this search; absence is not evidence that no paper exists." |
| Design label from the library | "Design as labeled by the library (confidence N)", never as a finding. |

## Never

- Never fill a definition, dose, threshold, owner or benchmark from memory.
- Never impute missing events or assessments.
- Never treat a KPI with no data as zero.
