# Gap rules

A gap is information. Each reason for a gap leads to a different next step, so name the reason.

## Criteria facts

| Class | When | How to word it | Next step |
|---|---|---|---|
| Sourced | A research row states it. | The criterion plus the row id (for example "GRIPP2-SF, five items, PE-91"). | None. |
| Method paper | The row is marked [PAPER]. | Cite the DOI; say it is a published method, not a rule. | None. |
| Framework, not rule | UK Standards (PE-65). | "A framework, not a mandated rule (PE-65)." | None. |
| Register rule | An R row. | "Register starting rule R-14, yours to adopt." | Ask whether the person adopts it. |
| Context, not target | NICE lay members (PE-61). | "NICE's rule for its own committees; context only." | None. |
| Not in the sources | GRIPP2-LF item list, a co-design sample size, a pass mark for trace coverage, consent elements. | "Not in this skill's sources `[GAP]`." | The person sets the rule, or checks the primary source. |

## The person's data

| Situation | How to word it |
|---|---|
| No changes file | No trace. Ask for the release's changes with a "credited to co-design" column. |
| A change credited to co-design with no insight link | "Credited, no capture link: not from this research (R-18)." |
| No backlog date | The "planned before capture" check cannot run: "backlog date not recorded `[GAP]`." |
| No planned participant types | Fit cannot be checked: ask for the research question's participant types (R-19). |
| No rule for trace coverage, repeated points or decision dates | Report numbers; "no rule set"; no verdict. |
| No owner | Use the owner or role the person names, in their words. Only if they named none, write "owner not named" and ask. Never suggest a job title. |
| Identifiers in a file | Stop; ask the person to remove them. |

## Never

- Never fill a capture, a link, a date, an owner, a score or a decision from memory or from what seems likely.
- Never read "traced" as "worked" or "patients benefited".
- Never treat a missing capture as proof the change was not patient-driven; it is unproven by this research.
