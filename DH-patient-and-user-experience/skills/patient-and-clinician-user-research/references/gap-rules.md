# Gap rules

A gap is information. Name the reason, because each reason leads to a different next step.

## Source facts

| Class | When | How to word it | Next step |
|---|---|---|---|
| Sourced | A row states it. | The fact plus the row id (for example "FDA bars think-aloud in validation, UX-US-40"). | None. |
| Guidance, not law | The row is FDA or MHRA guidance or NHS policy. | Say "FDA recommends" or "NHS guidance", never "required" (UX-US-26, UX-UK-14, UX-UK-25). | None. |
| Restated, not read | The figure comes from a paper or book quoted by another source (Faulkner via FDA; Sauro and Lewis via Hyzy). | "As restated by FDA (UX-M-01); the original was not read." | Read the original before relying on it outside the conversation. |
| Paywalled standard | IEC 62366-1 or IEC/TR 62366-2 text. | "Clause text not in the sources `[GAP]`." | The person's licensed copy. |
| Not sourced | No row covers it (SUS adjective bands, consent elements, payment rules, EU ethics review). | "Not in this skill's sources `[GAP]`." | Ask the owner or point to the pack that holds it. |
| Version | A row records a version change (FDA HF guidance reissued 3 August 2026; HF content guidance final 29 May 2026). | Cite the current version; call older text superseded. | None. |

## The person's facts

| Situation | How to word it |
|---|---|
| No decision named for the study | Ask. A study without a decision cannot be planned. |
| User group not stated for a participant | "Group not recorded `[GAP]`"; the participant is not counted in any group. |
| No critical-task flag | "Critical tasks not flagged by the owner `[GAP]`"; do not decide. |
| No rule for "repeated" | List every stop with its count; no "repeated" label. Offer the register starter rule for adoption. |
| No owner named | Use the owner or role the person names, in their words. Only if they named none, write "owner not named" and ask. Never suggest a job title. |
| No release or date | "Not set"; never propose a date. |
| SUS response incomplete | "Excluded, item missing; no imputation rule in the sources `[GAP]`." |
| No scores for ranking | No ranking. Ask for reach, impact, confidence and effort. |

## Library facts

| Situation | How to word it |
|---|---|
| No safety events returned | "No events in the library for this query; absence is not evidence of no events." |
| Guidance passage without a source URL | Do not use it. |
| Verify returns "supported" for a claim the passage does not state in the same direction | Do not accept it (register N3); quote the passage instead. |

## Never

- Fill a requirement, threshold, sample size, critical-task list, owner or date from memory.
- Treat a missing row as "not required" or a missing event as "safe".
