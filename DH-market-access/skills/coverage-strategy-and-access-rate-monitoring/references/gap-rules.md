# Gap rules

A gap is information. The person needs to know why something is missing, because each reason leads to a different next step.

## Coverage facts from the library

| Class | When | How to word it | Next step |
|---|---|---|---|
| Found | The product has a status row. | Status, plain meaning, listing date, retrieval date. | None. |
| Field missing | The row exists but a field is empty (end date, price, the date a status changed). | "Listed on trial since 18 February 2025; the library does not store an end date `[GAP]`." | Check the authority's page. |
| Scheme loaded, product not found | The scheme has listings in the library but none for this product. | "Not in the library's copy of this scheme (N listings, loaded DATE)." | Check the authority before concluding. |
| Scheme not loaded | The library holds no listings for the scheme. | "The library holds no data for this scheme." | The library cannot answer; check the authority. |

## Change over time

| Situation | How to word it |
|---|---|
| Only one snapshot exists | "The library shows the current status only; when it changed is `[GAP]`." Never infer a change date from `listed_on`. |
| Two of your own runs differ | State both runs with their dates and what changed. |
| Status and stored passage disagree | Quote both and say "check the register". |

## Uptake facts

| Situation | How to word it |
|---|---|
| The person has not given a count for a stage | "Not measured `[GAP]`", and name who would hold it (`uptake-measures.md`). |
| No official national figure exists | "No official figure for this market." Never borrow another country's. |
| Counts in different units | Keep them apart and name each unit. |

## Never

- Never turn a gap into "not reimbursed", "lapsed", "failed" or "stalled". A stall is a measured miss against a rule the person set.
- Never fill a gap from memory or a passage without a source URL.
