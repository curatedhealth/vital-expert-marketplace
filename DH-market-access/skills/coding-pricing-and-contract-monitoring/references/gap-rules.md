# Gap rules

## Code and price changes

| Situation | How to word it | Next step |
|---|---|---|
| Change published and read | What changed, effective date, row id. | None. |
| Proposed, final not read | "Proposed DATE; final rule not published as of the read date." | Read the final rule when published. |
| Library shows only today's value | "The library holds the current value only (snapshot DATE); when it changed is `[GAP]`." | Compare with the person's earlier run or contract value. |
| Not sourced | `[GAP]` with the "Not sourced" item (for example LATM amounts, CEPS clauses, national RPM amounts outside the stored codes). | Name the authority. |

## Contract performance

| Situation | How to word it |
|---|---|
| The person gave no count for a measure | "Not measured `[GAP]`", and who holds it (billing system, payer remittance, outcome data provider). |
| No rule set for a measure | "No rule set", and no verdict. |
| Statutory floor differs from the contract term | Show both, labeled. |
| Units differ (claims, prescriptions, months) | Keep them apart and name each unit. |

## Never

- Never turn a gap into "price cut", "code deleted" or "contract failed".
- Never infer a change date from a snapshot date or a listing date.
- Never fill an amount from memory.
