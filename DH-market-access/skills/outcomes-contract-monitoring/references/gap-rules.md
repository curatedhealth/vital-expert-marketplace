# Gap rules

A gap is information. Say why something is missing, because each reason leads to a different next step.

| Situation | How to word it | Next step |
|---|---|---|
| The contract's rule for a case is not given (below a baseline cut-off, a late value, a self-reported value) | "Contract rule not given `[GAP]`; computed both ways" | Ask the person; show both results |
| A value is missing for a patient | "Missing" in the patient table; count it under the contract's rule | A2 explains the effect |
| A data field is not collected at all (collection date, self-report flag) | "Not collected `[GAP]`: validity and self-report checks not possible" | Name who would hold it |
| The person has not named an owner | "Owner not named" | Ask; never assign |
| No pass rule for a measure | "No rule set: factual summary only" | No verdict for that measure |
| Official data not yet available (AbEM before 15 April 2027) | "Not available until DATE" | Track on the person's own data |
| The library holds nothing for the question | "The library holds no outcome-contract data" | Work from the person's data |

## Never

- Never turn a missing value into a judgment of the product, the patient or the team.
- Never fill a missing value, impute one, or drop a patient the contract keeps.
- Never present a gap between attainment and threshold as a forecast of the final result.
