# Gap and finding rules

## Checklist items (A1)

| Class | When | How to word it |
|---|---|---|
| Present | The draft contains it | "Present: [heading, page]" |
| Missing | The draft clearly lacks it | "Missing: [item] (row)" |
| `[GAP]` | The draft does not let you tell (section list only, illegible, cross-reference to an annex not supplied) | "`[GAP]`: cannot tell from the material supplied; [what to supply]" |
| Not applicable | The route does not ask for it | "Not applicable to [route] (row)" |

A finding is a fact plus the rule it rests on. Never an adjective about quality, never a score.

## Decisions (A2)

| Class | When | How to word it |
|---|---|---|
| Decided | A published row or the person's document states the decision | Decision, date, source |
| Pending | The person's document shows filing, no decision | "Pending since DATE; clock (row)" |
| Stale in the library | A stated end date has passed and the status has not moved | "Stated end DATE has passed; status not updated in the library copy; check [authority]" |
| Not published | The body does not publish it (BfArM refusals, applicants, review days) | "Not published by [body] (row)" |
| Not in the library | The body publishes it but the library does not hold it (CNEDiMTS opinions, FR_LPPR) | "Published by [body]; not in the library; check [where]" |

## Rules and verdicts (B1)

- A body without person-set rules gets a factual summary and no verdict.
- A rule whose fact is missing is "not measurable `[GAP]`", never pass or miss.

## Never

- Never turn "not published" or "not in the library" into "no decision" or "refused".
- Never infer an outcome from a passed end date.
- Never use a national rate as the person's rule, target or odds.
- Never fill a gap from memory.
