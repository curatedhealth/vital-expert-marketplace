# Gap rules

A gap is information. Say why something is missing, because each reason leads to a different next step.

| Situation | How to word it | Next step |
|---|---|---|
| The person has not named a measure, data source or owner | "Owner not named `[GAP]`" or "Data source not named `[GAP]`" | Ask; do not fill |
| An official rule is not set yet (German framework method for the 20 percent component) | "The law sets the floor; the framework method is not set `[GAP]` (framework agreement valid from 28 February 2024 is the latest listed)" | Treat the term as a proposal for negotiation |
| A sourced row is missing a detail (full ACCESS measure list per track, AbEM PROM instrument names, ISPOR taxonomy wording) | "Not in the sourced rows `[GAP]`; read DOCUMENT" | Read the named document before relying on it |
| A data source will exist only later (AbEM PROMs from Stage II, 2027) | "Not available until STAGE `[GAP]`" | Use an interim measure or a conditional term |
| A literature claim could not be checked (`check_claim` unverifiable, or the value is not in the passage) | "Not verified: REASON" | Read the full paper; do not quote the value |
| The library holds nothing for the question | "The library holds no outcome-contract data" | Method from references; facts from the person |
| A [WF] row (read through a summarizer) | "Read through a summarizer; re-read on the live page" | Re-read before external use |

## Never

- Never fill a gap from memory, or from a passage without a source URL.
- Never present a comparator's recorded price as its contract terms, or as evidence that it has an outcome component.
- Never turn "no framework method" into "no obligation": the 20 percent floor is law since 1 January 2026.
