# Sample data (ILLUSTRATIVE)

Every file in this folder is illustrative, typed for the build and the evals. "GlucoStep" and "CardioTrack" are invented products and the people named are invented. The CVE ids (CVE-2099-nnnnn) are deliberately fictional, and `kev_list_illustrative.csv` is not CISA's catalog: in real use the person downloads the KEV list themselves. None of these files is a real company's hazard list, test record, release log, SBOM, capacity record or placement table. Use only to test `scripts/delivery_check.py`.
