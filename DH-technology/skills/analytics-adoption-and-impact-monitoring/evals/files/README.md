# Sample data (ILLUSTRATIVE)

Every file in this folder is illustrative, typed or generated for the build and the evals. None is a real hospital's or company's roster, usage log, report log, outcome file or register, and the people and sites named are invented. Use only to test `scripts/adoption_check.py`.

- `roster_illustrative.csv` and `events_illustrative.csv` 48 people at three invented sites (seed 11) for a discharge follow-up worklist; one event outside the window and one for a person not on the roster, on purpose.
- `report_issues_illustrative.csv` four issues of a monthly report, with a reused timestamp, a missed issue and a late issue.
- `decision_outcome_illustrative.csv` the bet metric before and after the worklist (before-after comparison, users not given for the comparison period).
- `worklist_cases_illustrative.csv` ten worklist recommendations with the action taken and any reason for variation.
- `metric_register_illustrative.csv` and `publishers_illustrative.csv` certification status and publish rights.
