# Eval files

ILLUSTRATIVE files written for these evals by the build script (fixed seed). Not real patients, sites, models or people. The same files are in `examples/sample-data/`.

- `model_register_illustrative.csv`: four model versions with record fields and drift watch fields
- `record_rule_illustrative.json`: the person's record pass rule, written 1 June 2026
- `prediction_log_illustrative.csv`: period, id, sex, age_band, lactate, p, y for 2026-Q1 to 2026-Q3 (1,560 predictions; 75 Q3 outcomes pending)
- `monitoring_thresholds_illustrative.json`: the person's thresholds, written 15 December 2025
- `decision_log_illustrative.csv`: 1,120 decisions of a sleep-program engine, 1 to 28 September 2026
- `decision_rules_illustrative.csv`: the engine's rule table
