# DH Cybersecurity & Privacy

Install **DH Cybersecurity & Privacy** from `curatedhealth/vital-expert-marketplace`, then paste the Digital Health Library key. The key is not in this pack.

This pack is only DH-04.02 Cybersecurity & Privacy. Other Digital Health cores are separate packs.

The connector is `https://mcp.vital.expert/api/mcp/library`. Do not add a second connector.

Choose one heading, then one job. The job holds its tasks as sections. Ask which one task, then follow that section. A missing fact stays a gap.
