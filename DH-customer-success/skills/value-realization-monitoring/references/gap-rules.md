# Gap rules

A gap is information. Each reason for a gap leads to a different next step, so name the reason.

## Knowledge facts

| Class | When | How to word it | Next step |
|---|---|---|---|
| Sourced | A CS row states it | The fact plus the row id ("PHQ-9 10 or more = moderate band, CS92") | None |
| Abstract only | The row is [PAPER, abstract] | Add "per the abstract" once | Read the full text before external use |
| Not sourced | Customer health score, NRR, churn, expansion, time-to-value, NPS rules; GAD-7 cut points; PAM levels; a PHQ-9 minimal important difference | "Not in this skill's sources `[GAP]`; this is your rule to set" | Ask the person for their definition, label it O |
| Read by a summarizer | A [WF] row (DTAC, DCB0160) | "Read through a summarizer [WF]; re-check on the page before relying on it" | Re-read the live page |
| Period-specific | ACCESS thresholds | "For the Effective Period 5 July 2026 to 31 December 2027 (CS84); CMS may update them" | Check the current CMS document |
| Payment-linked | Any outcome tied to payment | "Payment-linked outcomes are Market Access's subject" | Point to `outcomes-contract-monitoring` |

## The person's facts

| Situation | How to word it |
|---|---|
| No target for a signal | Report the number; "no target set"; ask |
| No health rule | Signals met and missed per account; "no rule set: no health status" |
| No denominator basis | "Denominator basis not stated `[GAP]`"; a share without its basis is not reach (CS27) |
| Denominator basis differs from the target's | "Not comparable"; do not mark met or missed |
| No data for a signal in the period | "Not measured `[GAP]`"; name the field or report that would hold it |
| Sent note with no author in the record | "Author not in the record"; never guess |
| No previous target version | "Previous targets not supplied"; changes cannot be shown |
| No rounding tolerance | Match exactly and say so; ask for the tolerance |
| No owner named | "Owner not named"; ask. Never suggest a job title |
| No forum or date for a next action | "Forum and date not set"; ask. Never propose a date |
| No scores for ranking | No ranking; lay out the facts per action and ask for scores |

## Library facts

| Situation | How to word it |
|---|---|
| Literature record without abstract text | "Record found; abstract not returned by the library" and use the row in the research file instead |
| Verify returns "supported" | Accept only if you read the passage and it states the claim in the same direction (register N3) |
| Verify rates an official page "no provenance" | Use the research row with its quote and URL; say Verify could not admit the page (register C1) |

## Never

- Fill a target, threshold, band, owner, score or date from memory.
- Treat a missing signal as a met one, or no complaints as health.
- Treat a missing row as "not required".
