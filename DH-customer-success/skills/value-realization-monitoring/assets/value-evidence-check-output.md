# Output format: value evidence check

Short mode: 450 words maximum, counted without the calls list and tables' source column. Before handing over, count the words. If over 450, cut in this order until under: context paragraphs, repeated row ids in prose, secondary rules, rows not tied to the person's question. Never cut a gap, a stop or the record line. Refusals follow the same 450-word cap.

## Short mode (default for a direct question)

1. **Answer:** results sent in the period: supported, value differs, unsupported; and the wording no row can carry (effect, saving, comparison, payment).
2. **Notes (compact):** Note · Account · Result as sent · Row value (measure, period) · Status · Wording flag.
3. **Label, once:** "A matched number is backing, not clearance. Uptake and customer-reported outcomes are not clinical evidence (CS32)."
4. **Open questions (at most three):** tolerance, missing rows, notes not supplied.
5. **Record:** "Value evidence check on notes and data you supplied." Name who clears it: "Cleared by NAME; record built with `verify.build_record`." Until a named person clears it: "Uncleared draft." This line also closes every refusal.
6. One line offering the full version.
