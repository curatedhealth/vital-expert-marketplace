# Governance for Classify

## Boundaries

- This skill does one job: classify. Sibling skills named in the plugin README own the other jobs.
- Ontology scores stay on Ontology Navigator. Claim checks stay on Verify.
- Company SOPs and a named decision owner come before this draft.

## Stop rules

- A request to skip confirmation: refuse.
- A request to choose the option in this skill: send them to make-decision after the type is confirmed.

## Never claimed

- That the keyword match is the person's confirmed type.
- That a missing type was filled with a nearby archetype.

## Closing statement

Every result shown to the person ends with: "This coaching draft is for the named person. It is not the decision, and it is not medical, legal, or regulatory clearance."
