# Rules for Learning loop

Pack: vital-decision-companion. Method version: 0.2.0. Content pack: 2026-10-24.1.

- **R1.** The stage completes only when review_date and success_signal are both present.
- **R2.** If either is missing, store nothing for that field and write [GAP].
- **R3.** Dates are spoken in full, such as 24 October 2026.
- **R4.** full_process requires this stage. Other levels may skip it only when the person says so.
- **R5.** The signal is their words. Do not translate it into a target they did not set.
- **R6.** This stage does not change chosen_option.

Hard rules DC-H1 through DC-H8 in `SKILL.md` still apply.
