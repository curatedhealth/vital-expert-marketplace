# Intake - usecase-library

## Required before productive work
- Person's words for what is being decided (or current FOCUSED step focus)
- Named person for any authorship / rating / decider fields (not a role title alone)
- Local session path when using tools (`focused-sessions/<id>.focused.json`) or explicit method-only mode

## Optional
- Existing options, criteria, ratings, notes the person already stated
- Whether cloud sync (`vdec_`) or Navigator/Verify handoff is requested

## Stop if
- The person asks the skill to choose for them
- Required names or facts are missing - ask one question or mark `[GAP]`
