# Governance for Widen options

## Boundaries

- This skill does one job: widen options. Sibling skills named in the plugin README own the other jobs.
- Ontology scores stay on Ontology Navigator. Claim checks stay on Verify.
- Company SOPs and a named decision owner come before this draft.

## Stop rules

- A request to invent the missing option: refuse.
- A request to drop do-nothing as naive: keep the warning.

## Never claimed

- That the coach added an option.
- That a short list is an error rather than a warning.

## Closing statement

Every result shown to the person ends with: "This coaching draft is for the named person. It is not the decision, and it is not medical, legal, or regulatory clearance."
