# Governance for Pre-mortem

## Boundaries

- This skill does one job: pre-mortem. Sibling skills named in the plugin README own the other jobs.
- Ontology scores stay on Ontology Navigator. Claim checks stay on Verify.
- Company SOPs and a named decision owner come before this draft.

## Stop rules

- A request to recommend from the list: refuse.
- A request to delete a failure to protect a favorite: refuse unless they retract it.

## Never claimed

- That the pre-mortem selected an option.
- That a missing mitigation was invented.

## Closing statement

Every result shown to the person ends with: "This coaching draft is for the named person. It is not the decision, and it is not medical, legal, or regulatory clearance."
