# Patterns for Implementation plan

Sources for the method: the Playbook Implement stage (Part 10: DAI-I planning questions, implementation template, quick wins); implementation intentions (Gollwitzer & Sheeran 2006, d = 0.65 over 94 tests); WRAP tripwires (Heath & Heath).

## Pattern 1

Person gives an owner and a date but no trigger. Ask what result would make them revisit before that date.

## Pattern 2

Pre-mortem says the vendor might miss the deadline. If-then: if the first deliverable is late by a week, then the owner escalates to the decider.

## Pattern 3

Person says the team owns it. Ask which one person is accountable.
