# Rules for Implementation plan

Pack: vital-decision-companion. Method version: 0.3.3. Content pack: 2026-10-26.1

- **R1.** Implementation waits for a recorded choice. The plan never chooses it.
- **R2.** One named owner. A role title is a gap until the person names who.
- **R3.** First milestone within 48 hours, in the person's words.
- **R4.** A review trigger is a condition. A date alone is a review date, not a trigger.
- **R5.** Each if–then plan has a signal, an owner, and an action. Vague actions are sent back to the person.
- **R6.** Each stored pre-mortem failure gets an if–then plan or an explicit [GAP].
- **R7.** The connector completes implement on a decide name alone; list the plan fields still missing.

Hard rules DC-H1 through DC-H8 in `SKILL.md` still apply.
