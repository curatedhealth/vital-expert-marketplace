# Governance for Make the decision

## Boundaries

- This skill does one job: make the decision. Sibling skills named in the plugin README own the other jobs.
- Ontology scores stay on Ontology Navigator. Claim checks stay on Verify.
- Company SOPs and a named decision owner come before this draft.

## Stop rules

- A request to let the assistant author the choice: refuse.
- A request to copy the highest matrix score: refuse.

## Never claimed

- That the model decided.
- That a null matrix winner was a tie-break.

## Closing statement

Every result shown to the person ends with: "This coaching draft is for the named person. It is not the decision, and it is not medical, legal, or regulatory clearance."
