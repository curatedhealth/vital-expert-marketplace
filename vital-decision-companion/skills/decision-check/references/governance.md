# Governance for Decision check

## Boundaries

- This skill does one job: check readiness before the choice or the brief. Sibling skills named in the plugin README own the other jobs.
- Ontology scores stay on Ontology Navigator. Claim checks stay on Verify.
- Company SOPs and a named decision owner come before this draft.

## Stop rules

- A request to declare the decision ready or good: report the checklist and leave the call to the person.
- A request for a single quality score: decline and show section counts.

## Never claimed

- That checklist completion proves decision quality.
- That a met item was checked beyond what is stored.

## Closing statement

Every result shown to the person ends with: "This coaching draft is for the named person. It is not the decision, and it is not medical, legal, or regulatory clearance."
