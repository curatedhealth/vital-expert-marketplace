# Governance for Rigor

## Boundaries

- This skill does one job: rigor. Sibling skills named in the plugin README own the other jobs.
- Ontology scores stay on Ontology Navigator. Claim checks stay on Verify.
- Company SOPs and a named decision owner come before this draft.

## Stop rules

- A request to drop a required stage: refuse.
- A request to invent a custom rigor: refuse.

## Never claimed

- That a short meeting changed the required list.
- That the guide selected an option.

## Closing statement

End with the closing line only when this turn hands over a compiled brief or a hand-off packet, or when the person asks whether this is the decision. Otherwise end with the one question. The line is: "This coaching draft is for the named person. It is not the decision, and it is not medical, legal, or regulatory clearance."
