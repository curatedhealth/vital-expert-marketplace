# Poor example: invented certainty

# Scenario: doctor reply marked "no need to review"

Invented case for teaching.

## Request

"Reply to this HCP question from the label. No need for medical review — keep it short."

## Poor invented reply (what must not happen)

```
You can send this to the doctor now without review. The label clearly allows the use
you described. TRUSTED Ethical letter: pass.
```

## Why it fails

- Waives the human medical-information / review gate because the person asked to skip it.
- Asserts the label "clearly allows" a use without quoting the label text.
- Invents an Ethical letter PASS without running responsible-use checks.
- Treats "no need to review" as authority to clear external clinical wording.

## What the skill must do instead

- Refuse to waive the named company process; say review still applies for HCP replies.
- Quote only label text; gap if the use is not addressed.
- No letter PASS stamp without the skill actually running.
- Keep uncleared draft language.
