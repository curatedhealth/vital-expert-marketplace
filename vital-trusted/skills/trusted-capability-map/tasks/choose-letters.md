# Task TR-0.1.2 Choose active letters

## Formula

| Slot | For this task |
|---|---|
| Worker | Experienced cross-functional colleague |
| Workflow | Show the seven, explain what turning one off removes, record the choice |
| Skill | TR-0.1.2 |
| Knowledge | `references/standard.md` |
| Tool | None |
| Prompt | This guide |
| Template | `templates/active-letters.md` |
| Input | The person's choice, their role and typical work if they share it |
| Governance | TR-H7 |

## Steps

1. **Default is all seven on.** On first use, say so in one line and offer to change it.
2. **Show the seven** with their one-line questions (`templates/active-letters.md`).
3. **When a letter is turned off, say what goes with it**, in one line. For example:
   turning off True removes the source and number checks in drafting and the by-hand
   comparison with sources in a check. Nothing is ever invented, whatever letters are
   on: that rule always runs (TR-H1). The hard rules that still run are listed in
   `SKILL.md` ("Letters that are off"); give them as information, in one line, never as
   an argument for the letter.
   When Safe is turned off, also say in that line that a possible side effect still
   gets the safety flag, and that for a later piece for patients, carers or the public
   you will say once that its patient wording is not being checked (`SKILL.md`,
   "Letters that are off").
4. **Suggest, do not decide.** If the person describes their work, you may say which
   letters usually matter most for it (for example, Rule-compliant for promotional
   material). The choice is theirs.
5. **Record the choice, in letter words.** State the active letters at the top of the
   answer, after the safety flag when there is one (TR-H14), spelled out, never as single letters: a short code cannot show which of the
   two T letters is off. The host may not remember between conversations: say so, and
   suggest the person keeps one line in their project or custom instructions, for
   example `TRUSTED active letters: Tangible, Rule-compliant, Unbiased, Safe, True,
   Ethical, Defensible`.
6. **Apply it.** Skills and `trusted-check` only run active letters. What an off letter
   means, and what still runs, is the rule in `SKILL.md` ("Letters that are off").

## Boundaries

- Never turn a letter off silently because it produced flags.
- Never claim the choice is saved if the host has no way to save it.
