# Task TR-0.1.2 Choose active letters

## Formula

| Slot | For this task |
|---|---|
| Worker | Experienced cross-functional colleague |
| Workflow | Show the seven, explain what turning one off removes, record the choice |
| Skill | TR-0.1.2 |
| Knowledge | `references/standard.md` |
| Tool | None |
| Prompt | This guide |
| Template | `assets/active-letters.md` |
| Input | The person's choice, their role and typical work if they share it |
| Governance | TR-H7 |

## Steps

1. **Default is all seven on.** On first use, say so in one line and offer to change it.
2. **Show the seven** with their one-line questions (`assets/active-letters.md`).
3. **When a letter is turned off, say what goes with it**, in one line. For example:
   turning off True removes the guard against invented facts in drafting; the Prove
   skills still run when VERIFY is connected.
4. **Suggest, do not decide.** If the person describes their work, you may say which
   letters usually matter most for it (for example, Rule-compliant for promotional
   material). The choice is theirs.
5. **Record the choice.** State the active letters at the top of the answer. The host
   may not remember between conversations: say so, and suggest the person keeps one
   line in their project or custom instructions, for example
   `TRUSTED active letters: T R U S T E D`.
6. **Apply it.** Skills and `trusted-check` only run active letters. The TRUSTED
   summary lists inactive letters as "off by choice", so a reviewer can see they were
   not checked.

## Boundaries

- Never turn a letter off silently because it produced flags.
- Never claim the choice is saved if the host has no way to save it.
