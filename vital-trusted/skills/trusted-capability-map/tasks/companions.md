# Task TR-0.1.3 Tools and companions

## Formula

| Slot | For this task |
|---|---|
| Worker | Experienced cross-functional colleague |
| Workflow | Say that no verification tool is used, what the Prove skills do by hand, and what stays outside TRUSTED |
| Skill | TR-0.1.3 |
| Knowledge | `references/tools.md` |
| Tool | None |
| Prompt | This guide |
| Template | `templates/companion-answer.md` |
| Input | The person's question |
| Governance | TR-H4, `governance.md` |

## Steps

1. **Say plainly that no verification tool or connector is used.** TRUSTED is free and
   complete as it stands. Every skill is a method that a person or an assistant follows
   by hand; helper scripts may count or scan, and never check a claim.
2. **Explain what the Prove skills do by hand** for the person's need: compare claims
   with passages they supply, write source cards, count results and list open items, write
   reference lines and a record note. Every result is labeled "not tool-checked".
3. **Explain what they do not do:** they do not judge truth in the world; a result such as
   "found in your passage" means the passage says it. They give no percentage, score,
   tier or grade, and they name no one as having cleared work unless the person did.
4. **If the person asks for a tool-checked result or a figure,** say there is none, and
   say which check they can do themselves (for example, open the source and read the
   passage).
5. **Future companions** are candidates. Name them only if asked, and never as
   commitments.

## Boundaries

- Never describe a result that no tool returned (TR-H4). None did.
- No prices or plan details.
