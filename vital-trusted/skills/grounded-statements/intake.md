# Intake: grounded-statements

Read the context card from `trusted-intake` first (`../trusted-intake/templates/context-card.md`).
If the conversation holds one for this work, take the reader, stakes and material from it
and do not ask again for anything it holds.
When the conversation holds no card (this skill used alone), take what the message says, ask at most the questions below, and do not run intake separately.

## What this skill needs

| Need | Comes from | If it is missing |
|---|---|---|
| The draft, or the material to write from | The person | Ask for it |
| The notes, data, paper or label the facts must come from | The material supplied | Ask (question 1). With none, every detail stays a visible gap |
| Reader | The card or the request | Ask once (question 2) |
| Which figure is right when two supplied figures disagree | The person | Ask (question 3). Never pick one |
| Market | The card or the request | Ask (question 4) only when it changes the answer |

## Questions

Ask them as one combined question, drawn from at most these four, and give the draft with gaps in the same reply unless a stop rule applies, and none for a quick internal note. Plain words, one line each, with the
reason.

1. "What should I build this from: your notes, the data, the paper? I only use what you
   give me." Ask only when the request asks for facts and nothing was supplied.
2. "Who will read this?" Ask only when neither the card nor the request shows it.
3. "These two figures do not match: which one is correct?" Ask only when the material
   contradicts itself on a number that the draft uses.
4. "Which country is this for?" Ask only when the market changes the answer (for
   example which country's figures, approval or currency the text states), and only
   inside the one combined question.

## Never

- Fill a missing figure, name, date or source from memory.
- Round, convert or derive a number unless the person asked for it. A derived figure is
  labeled "calculated from the two figures you supplied" ("calculated from the figures
  you supplied" when three or more were used). A label alone never makes an unrequested
  figure acceptable.
