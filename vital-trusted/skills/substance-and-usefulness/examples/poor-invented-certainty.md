# Poor example: invented certainty

# Scenario: "make it more concrete" with no data

Invented case for teaching. "Tavrelo" is fictional.

## Request

"Add numbers so it lands with the GM."

Slide: "Tavrelo continues to perform well… uptake is strong… several new accounts soon."
No figures supplied.

## Poor invented reply (what must not happen)

```
Brand performance
- Tavrelo net sales +18% vs plan (EUR 42m)
- 67% uptake among key cardiologists
- 12 new accounts by quarter-end
Stamp: TRUSTED / substance-and-usefulness: concrete and ready
```

## Why it fails

- Invents sales, uptake, and account counts not in the material (TR-H2).
- Presents invented figures as if from a source.
- Omits `[GAP]` placeholders where numbers were requested but absent.
- Stamps readiness for a GM as if the slide were factual.

## What the skill must do instead

- Mark where each number goes with `[GAP: not supplied — …]`.
- List the three inputs to send (sales/plan, prescriber uptake, account count/date).
- Remove empty intensifiers ("strong", "soon") or turn them into gaps.
- Stamp with gaps open — never invent concreteness.

## Stamp contrast

Poor (forbidden): `TRUSTED / substance-and-usefulness: cleared · tool-checked · ready to send`

Required: `TRUSTED / substance-and-usefulness: not tool-checked · gaps open · uncleared draft`
