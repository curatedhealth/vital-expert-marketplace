# Gap rules applied to sourced claims

> **Where the marker belongs.** Use the `[GAP: …]` marker only inside a drafted deliverable. In notes, open-item lists and explanations, write the gap as a plain sentence ("Still missing: …, from …"). See `trusted-capability-map/references/gap-rules.md`.

Same format and classes as every TRUSTED skill:
`[GAP: <class> — <what is missing> — <what would close it>]`

| Class | Typical case in this skill | Example |
|---|---|---|
| `not supplied` | A claim has no source in the material; a source is named but the document was not given; a citation field is missing | `[GAP: not supplied — source for "1 in 20 adults" — supply the prevalence study or registry report]` |
| `not supplied` (weaker source only) | The only supplied source is a type that cannot carry the claim for this reader | `[GAP: not supplied — trial publication behind the news report of a 60% reduction — find the primary record]` |
| `out of date or unclear date` | "Current", "latest", "now" with no date; guidance named without a date or version | `[GAP: out of date or unclear date — "current guideline" has no title or edition — name the document and year]` |
| `conflicting` | Two supplied sources give different values or positions for the same claim | `[GAP: conflicting — press release says 58%, poster says 54% — confirm which is final]` |
| `not checkable here` | Whether a specific source is peer reviewed, retracted, superseded or exists as cited, when VERIFY is not connected | `[GAP: not checkable here — whether this preprint has since been published — check with source-assessment or your literature team]` |
| `needs a decision` | Whether data on file can be used and provided on request; whether a weaker source is acceptable for an internal use | `[GAP: needs a decision — whether this data on file can be provided to the payer — ask your medical or promotional review]` |

Wording rules:

- Name the exact claim the source is for, in quotation marks if short.
- Name the kind of source that would close the gap, never a specific reference you
  have not been given. "Supply the trial publication" is right; "supply Meyer 2023" is
  a recalled reference unless the person named it.
- Never hint at the answer inside a gap ("probably the 2024 guideline").
- A person-named reference not yet supplied is `not supplied`, not a citation.
