# Primary rules behind this skill

Each rule names its primary source, the date and how it was confirmed. A rule marked
`[CHECK]` has not been confirmed against the primary document, or its scope or currency
is open; it is applied as good practice, not cited as a requirement (TR-H8).

Industry codes bind their members in the markets they cover. Outside that scope, apply
the rule as good practice only. The company's own review process decides which code
applies to a piece of work (TR-H11).

Last reviewed: 20 October 2026.

## How to use these rules in output

- In what the person reads, state the practice in plain words ("a payer will expect to
  see the data behind this figure"). Name a rule only if they ask (TR-H13).
- Never extend a rule beyond its scope. R1 to R4 are UK code rules; R9 is US payor
  communications only; R10 is journal practice.
- Never say a draft meets a code. Say what is sourced and what is open.
