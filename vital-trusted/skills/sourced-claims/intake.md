# Intake: sourced-claims

Read the context card from `trusted-intake` first (`../trusted-intake/templates/context-card.md`).
If the conversation holds one for this work, take the reader, market, stakes and material
from it and do not ask again for anything it holds.
When the conversation holds no card (this skill used alone), take what the message says, ask at most the questions below, and do not run intake separately.

## What this skill needs

| Need | Comes from | If it is missing |
|---|---|---|
| The draft with its claims | The person | Ask for it |
| Reader, because it sets which kind of source can carry a claim | The card or the request | Ask once (question 1) |
| The sources the person has for the claims | The material supplied | Ask (question 2). With none, the claims stay visible gaps |
| What "data on file" or "internal data" refers to | The person | Ask (question 3) only when the draft cites it |

## Questions

Ask them as one combined question, drawn from at most these three, and give the draft with gaps in the same reply unless a stop rule applies, and none for a quick internal note. Plain words, one line each, with the
reason.

1. "Who will read this?" Ask only when neither the card nor the request shows it.
2. "Which papers, documents or data do you have for these claims? I will not add sources
   of my own." Ask only when the draft makes factual claims and no sources were supplied.
3. "Can a reviewer open the data on file you mention, and where is it kept?" Ask only when
   the draft cites data on file and the material does not show what it is.

## Never

- Add a reference, an author, a page or a link that the person did not supply.
- Call a source good enough. Say what kind it is and what it can carry for this reader.
