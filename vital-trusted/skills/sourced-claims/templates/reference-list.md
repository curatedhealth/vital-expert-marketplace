# Output format: reference list

Built only from supplied sources. Every field comes from the document; a missing field is
a gap, never filled from memory. Style (numbering, punctuation) follows the person's
choice; the default below is plain and complete.

```
References (built from the sources you supplied; not checked with a tool)

1. <Authors>. <Title>. <Journal or body>. <Year>;<volume>:<pages or article number>.
   <DOI or PMID>. Used for: <claim, short>, <table, figure or section>.
2. <Body>. <Full title>. <Document type: final guidance | draft guidance | assessment
   report | decision>. <Date>. Section <x>. Used for: <claim>.
3. <Company>. Data on file: <specific data set name or reference>. <Date>. Available on
   request through <kind of process>. Used for: <claim>.
4. <Publisher>. <Title> (<press release | news | blog>). <Date>. <URL as supplied>.
   Used for: <what it can support, e.g. "the announcement">.

Missing details
- Reference <n>: [GAP: not supplied — <field, e.g. DOI and table number> — <from the
  full document>]

Claims with no reference yet
- "<claim>" — needs <kind of source>.
```
