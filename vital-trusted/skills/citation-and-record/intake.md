# Intake: citation-and-record

Read the context card from `trusted-intake` first (`../trusted-intake/templates/context-card.md`).
If the conversation holds one for this work, take the reader, stakes, material and next
process from it and do not ask again for anything it holds. References and the record are
written by hand. Each is labeled "not tool-checked".
When the conversation holds no card (this skill used alone), take what the message says, ask at most the questions below, and do not run intake separately.

## What this skill needs

| Need | Comes from | If it is missing |
|---|---|---|
| The details of each source: authors, title, journal, year, volume, pages, link or DOI | What the person supplied | Ask (question 1). A missing field stays missing and is named. It is never filled |
| The person who cleared the work, with role and date | The person | Ask (question 2) only when a record is wanted. Without a name the record is an uncleared draft |
| Reader, which sets the size of the record | The card or the request | Ask once (question 3) |

## Questions

Ask them as one combined question, drawn from at most these three, and give the draft with gaps in the same reply unless a stop rule applies. None for a quick internal note, where the everyday note from `work-record`
is enough. Plain words, one line each, with the reason.

1. "Can you paste the details for each source, or the links or DOIs?" Ask only when the
   details are not in the conversation.
2. "Has someone reviewed and cleared this? If so, who, in what role, and on what date?"
   Ask only when a formal record is wanted.
3. "Who will read this?" Ask only when neither the card nor the request shows it.

If the person's process names a reference style, build the lines by hand in that style and
label them. Otherwise write plain lines from the details supplied.

## Never

- Put a name on a record that the owner did not give.
- Name the assistant or a tool as the person who cleared the work.
- Add an access date or a publisher that nobody supplied.
