# Output format: reference list

What the person sees. No caption before any line, no codes (TR-H13). Lines are copied from
the details the person supplied. No access date unless the person gave one.

```
1. <plain line from the supplied details, in the style the person named or in one consistent order>
2. <plain line from the supplied details>
3. <plain line from the supplied details>

<missing-detail lines, only if needed, as below>

Reference lines built from the details you gave; not tool-checked.
```

Only if needed, after the list, one plain line each:

```
<Source n> has no <year | pages | identifier> in what you gave me; I left it out. Add it from <where it would come from> if you have it.
You asked for <style>. I wrote these lines by hand from your details, so check the order and punctuation against the style guide.
```

## Never

- A caption such as "Reference:" before a line.
- An access date nobody supplied.
- A sentence saying the references show the claims are supported.
- A table, unless the person asked for the evidence table.
