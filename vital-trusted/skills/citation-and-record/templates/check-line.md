# Output format: check line for trusted-check

Returned to `trusted-check` only, never shown at the end of a direct reply. Counts and
plain notes; no verdict words (TR-H3, TR-H13). The shape follows the shared stamp: letter
word, aspect, counts, then "(not tool-checked)" at the end. The Defensible line here is the
formal record line; the everyday "Defensible · record:" line belongs to `work-record`
(`../../work-record/templates/check-line.md`), so the two never repeat each other.

```
True · references: <n> sources, <n> reference lines, <n> with a missing detail (not tool-checked)
Defensible · formal record: <n> sources, <n> open items, <n> handed on to a review process; <status, one of the forms in ../../work-record/templates/status-line.md> (not tool-checked)
```

If nothing was compared before the record was requested:

```
Defensible · formal record: Uncleared draft; claims not compared with their passages, <n> factual claims in the text (not tool-checked)
```
