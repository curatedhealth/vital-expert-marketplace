# Output format: check line for trusted-check

Returned to `trusted-check` only, never shown at the end of a direct reply. Counts and
plain notes; no verdict words (TR-H3, TR-H13).

```
True · references: <n> sources, <n> reference lines, <n> with a missing detail (<built with VERIFY | not tool-built>)
Defensible · record: <n> sources, <n> open items, <n> handed on to a review process; <cleared by <name>, <role> | uncleared draft> (<written with VERIFY | not tool-built>)
```

If nothing was checked before the record was requested:

```
Defensible · record: uncleared draft; claims not checked against their sources (<n> factual statements in the text)
```
