# Primary rules behind this skill

Each rule names its primary source, the date and how it was confirmed. A rule marked
`[CHECK]` has not been confirmed against the primary document; it is applied as good
practice and never cited as a requirement (TR-H8). Jurisdiction is stated for each.

Last reviewed: 20 October 2026.

## How to use these rules in output

- What the person reads describes the practice in plain words: "I put the everyday word
  first and the medical term in brackets after it, so the leaflet and the pack match."
  Name the guideline only if the person asks, or when the work is an EU package leaflet.
- R1 to R4 are rules for EU package leaflets. For other patient material (a patient
  support letter, an app screen, a website) say "good practice for patient material",
  not "required".
- R5 is a CDC tool for CDC products. Use its questions as prompts; never give a CDC
  Index score or say material "passes" it.
- Never cite R7, R8 or R9 as requirements.
- Rules for what a document must contain (required statements, fair balance, the route
  to a doctor) are in other skills: `market-rules-and-data`, `balanced-evidence`,
  `patient-safety`.
