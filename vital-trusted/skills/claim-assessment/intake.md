# Intake: claim-assessment

Read the context card from `trusted-intake` first (`../trusted-intake/templates/context-card.md`).
If the conversation holds one for this work, take the reader, stakes and material from it
and do not ask again for anything it holds. Claims are checked by hand against passages
the person supplied. Every result is labeled "not tool-checked".
When the conversation holds no card (this skill used alone), take what the message says, ask at most the questions below, and do not run intake separately.

## What this skill needs

| Need | Comes from | If it is missing |
|---|---|---|
| The text to check | The person | Ask for it |
| The passages it must be checked against: pasted words, or the pages | The material supplied | Ask (question 1). With none, the claims stay open as "no passage to compare with" |
| Reader, to set how many claims to check | The card or the request | Ask once (question 2) |

## Questions

At most two. Plain words, one line each, with the reason.

1. "Which source text should I check this against? Paste the passages, or the pages they
   are on. I only compare with what you give me." Ask only when the text makes factual
   claims and nothing was supplied.
2. "Who will read this?" Ask only when neither the card nor the request shows it and the
   number of claims to check would differ.

A request to mark claims as found without a check is declined in plain words, with an
offer to run the check.

## Never

- Check the text against memory, or against a passage the person did not give.
- Tidy a sentence into something easier to support and then check that instead.
- Ask whether a tool is connected.
