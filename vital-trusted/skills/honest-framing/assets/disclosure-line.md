# Output format: disclosure wording

Built only from what the supplied material states. Each piece comes from a named part of
the source (funding statement, disclosures, methods, data on file label). A missing
piece is a gap, never a guess. The company's own review process sets the final wording
of any company declaration (TR-H11); this is a draft for it.

## Short form, where the result is used (slide, key message, email)

```
<Study or source name>, <funded by | sponsored by | commissioned by | company data of>
<organization as stated>[, the maker of <product> | , which markets <product>].
```

Examples (fictional):

- "KELNA-1, a trial funded by Example Pharma, the maker of Velostra."
- "Company data on file: internal analysis of prescription data, Example Pharma,
  [GAP: not supplied — date of the analysis — add it from the data on file record]."
- "Market research commissioned by Example Pharma among 150 dermatologists."

## Full form, for a summary or reference note

```
Funding: <as stated in the source>.
Sponsor's role: <as stated, attributed: "the authors state …" | not stated in the source>.
Authors' ties: <as stated, e.g. "3 of 8 authors are employees of …; 2 received
consulting fees from …" | not stated in the source>.
Data access: <as stated | not stated in the source>.
```

Rules:

- "Not stated in the source" only when the full source was supplied and read; otherwise
  `[GAP: not supplied — funding and disclosures — supply the full paper]`.
- Never "independent", "no conflicts" or "unbiased" in this wording unless quoted and
  attributed to the source.
- No judgment of whether the interest affected the result, and none of whether a law or
  code requires the disclosure (TR-H6).
