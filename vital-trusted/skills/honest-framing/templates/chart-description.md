# Output format: plain description of a chart

Used when a chart is changed or needs changing. It tells the person what the reader
sees now and what the same data look like presented plainly, so they or their agency
can redraw it. It is a description, not a redraw, and never a verdict on the chart.

```
<Chart title or position, e.g. "Slide 4, bar chart of responders">

What it shows now: <chart type, axis range, series, n, period, as supplied>.
What the reader sees: <one plain sentence that describes the scale with the axis values
given, never with a ratio or a point difference, e.g. "The axis starts at 80%, not 0%,
and ends at 90%, so the bars for 88% and 84% look far apart.">
What the data are: <the values, both arms, n, period, e.g. "88% versus 84% of patients
at week 16 (n = 320 per arm)">.
Measured: <only if the person asked for the factor; leave the line out otherwise. The
label sits in the same sentence, e.g. "Calculated from the axis values you supplied,
the gap looks about 21 times its real size.">
Plainer version: <one or two sentences, e.g. "With the axis from 0% to 100%, the two
bars are almost the same height; the difference is easy to read if 88% and 84% are
printed on the bars.">
To change: <specific steps, e.g. "start the axis at 0%; print 88% and 84% on the bars;
add n per arm under the axis; add the source.">
Caption: <what the chart shows with both supplied figures, n and period, then one plain
clause on its own limitation, e.g. "Responders at week 16: 88% with Drug A, 84% with
placebo (n = 320 per arm). One trial over 16 weeks; not a comparison across trials.">
<If anything is missing:> [GAP: not supplied; <item>; <what would close it>]
```

No ratio anywhere in the description: not "six times as tall", not "1.4 times". A
factor appears only when the person asked for it, only on the Measured line, with its
label in the same sentence. A label alone never makes an unrequested factor acceptable.

State both supplied figures; never a derived point difference unless asked and labeled.
Wrong: "a rise of 15 points", "a 5-point difference". Right: "92% with Coravix and 87%
with the old device".

Every caption ends with one plain clause stating its own limitation (one trial, a
descriptive rate, a short period, a subgroup), never with a verdict on the chart.

When the person asks to keep the axis as it is, give two captions, both with the
limitation clause:
- As given: the caption for the chart as it is, with the axis start described plainly
  from the supplied values ("Axis starts at 84%, not 0%.").
- From zero: the caption for the same data with the axis starting at 0% and the values
  printed on the bars.
The person chooses which chart to use.

In the person's view, the gap is written in words ("the axis start is not in what you
sent; please add it"), not in gap syntax.
