# Output format: framing note

Follows the fixed text. Plain language, no rule codes, no pattern ids, no skill names
(TR-H13). Size it to the stakes (TR-H12): for an internal email, one or two lines; for
anything leaving the company, the full note. Never calls the result fair, balanced,
neutral or independent (TR-H3).

## Full note

```
How I changed the framing (Uncleared draft)

Based on: <one line per thing you supplied>

Strong words changed: <n>. Hedges removed: <n, only when the draft was over-hedged>.
Chart issues: <n>. Framing questions for you: <n>.
Other changes: <n> (<short kinds, e.g. causal claim softened, disclosure added,
unsupported claim removed>).

Changed
1. "<before>" → "<after>". <Why, in one plain sentence, e.g. "One trial cannot prove
   superiority; the result and its range now say how strong it is.">
2. ...

Charts
1. <Chart, where it is>: <what the reader sees now, in one sentence>. A version with
   <zero baseline / both arms / full period> shows <plain description>. To change:
   <specific steps>. Caption: <both supplied figures, n, period>; <one plain clause
   on its own limitation>.

Who stands behind the evidence
1. <Source>: <interest as the material states it>. Now stated <where>.

Kept out
1. "<wording asked for and not written>": <why, in one plain sentence>

Left as gaps for you to fill
1. <what is missing>: <where it would come from>

Question for you
<a choice only you can make, e.g. which timepoint the chart should show; one combined question at most, covering at most two related points (TR-H7)>

<If the work leaves the company:> Next step: this goes through your <kind of internal
process, e.g. promotional review> before it is used.

I compared the draft with what you gave me; none of this was tool-checked.
```

Leave out any section with nothing in it. The counts line is required in both forms
whenever something was changed or found, and shows only the counts that apply: leave
out a count that would read 0. Wording that was asked for and not written goes under
"Kept out", not in a count.
"Other changes: <n> (<short kinds>)" counts any change the named counts do not cover (a
causal claim softened, a disclosure added, an unsupported claim removed), so the main
fix is never uncounted.

## Nothing to change

No note and no counts line. One sentence, no verdict (never "fair", "fine", "good"):

```
Nothing needed changing in the framing: <what the text already does, e.g. it gives
both rates, the hazard ratio with its interval and the main harm in both arms>.
```

## Short note (internal, low stakes)

```
Strong words changed: <n>. <Hedges removed: <n>.> Chart issues: <n>.
Changed: <one line>. Gap left: <one line, if any>.
```
