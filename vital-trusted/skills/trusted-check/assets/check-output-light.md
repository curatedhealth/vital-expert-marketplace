# Output format: light TRUSTED summary (internal, quick)

Team emails, meeting notes for colleagues, a first brainstorm. A few lines. No table.

When something was found:

```
Quick check (<what it is>, for <reader>): <n> thing(s) to fix.
- <note: where and what, with the fix in a few words>
[Off by choice: <letters>.]
This check flags issues. It is not medical, legal, regulatory or ethics review.
```

When nothing was found:

```
Quick check (<what it is>, for <reader>): nothing flagged that would mislead a colleague.
[Off by choice: <letters>.]
This check flags issues. It is not medical, legal, regulatory or ethics review.
```

Add one line only if it matters:

- a source check is possible ("VERIFY can check the 2 figures against your report if
  you share it"), when VERIFY is connected and figures have no source;
- a hard-rule item (possible side effect, personal data), with its process.
