# Shared output cards (world-class UX)

Canonical scannable shapes for every TRUSTED skill. Skill-local `templates/` may specialize; when both exist, **prefer these** for Prove bundles and `trusted-check` summaries.

| Card | File | Use when |
|---|---|---|
| Claim | `claim-card.md` | One checkable claim vs a quoted passage |
| Finding | `finding-card.md` | Same as claim, numbered in a pack |
| Source | `source-card.md` | Qualify / grade a named source |
| Confidence | `confidence-card.md` | Faithfulness % + counts (never merges source score) |
| Evidence table | `evidence-table.md` | Full claim×status board |
| Gap list | `gap-list.md` | Open items only |
| Verify brief | `verify-brief.md` | Operator pack: counts → table → gaps → sources |
| Check-line stamp | `check-line-stamp.md` | Closing stamp every skill must emit |

**Grounding:** RAGAS atomic claims + faithfulness ratio ([docs](https://docs.ragas.io/en/latest/concepts/metrics/available_metrics/faithfulness/), accessed 8 Nov 2026); IFPMA 4.2/4.3 + ABPI 6.1/6.2 substantiation; FDA fair balance (21 CFR 202.1).
