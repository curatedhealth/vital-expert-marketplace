# Prove brief

A full pack for work leaving the company. Only when the person asks for it or the stakes
call for it. Each part uses the shared card of that name unless a skill has its own.

1. **Header.** Who the reader is, the market, the product status and the use, as the
   person gave them. Then: "Not tool-checked."
2. **Counts.** Use `confidence-card.md`.
3. **Evidence table.** Use `evidence-table.md`, only if asked.
4. **Open items.** Use `gap-list.md`.
5. **Sources.** One short source card per source, using `source-card.md`.
6. **References.** Reference lines built from the details the person supplied, with
   nothing filled in. If the person named a style, write the lines by hand in that style
   and say so; if they named none, write plain lines in one consistent order and choose no
   style for them. Missing details are listed as missing.
7. **Closing.** TRUSTED does not clear work. A named person, under your own process,
   decides whether it can be used.
