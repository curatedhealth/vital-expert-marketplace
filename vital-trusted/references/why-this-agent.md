# Why this agent owns TRUSTED

TRUSTED is a cross-cutting platform pack (letters T–D), not a single CF02 market-access capability. The steward is a thin AL00-style owner that:

1. Keeps one map-first entry so operators do not pick among nineteen skills blind.
2. Enforces offline-first Prove and human gates for healthcare-adjacent outputs.
3. Avoids inventing domain agents (HTA, HEOR, MedAff) that already exist as separate plugins.

A fuller multi-agent suite (source-qualifier, claim-checker, clearance-officer) remains deferred to the factory re-cut. Method depth lives in the CF04 skills; this agent only routes and holds the evidence rules.
