# Gap rules

A gap is information. Each reason for a gap leads to a different next step, so name the reason.

## The person's artifacts

| Situation | How to word it | Next step |
|---|---|---|
| Artifact named, no copy supplied | "Not measurable `[GAP]`: no in-market copy supplied" | Ask the sampler the person named for the current copy |
| Copy supplied is a draft or not in market | "Not scored: not the in-market copy" | Ask for the copy customers see |
| No positioning line on file | No check is possible; "line not on file `[GAP]`" | Run the segmentation skill, task B2 |
| No pass rule | Report present, altered or absent and the flags; no verdict | Ask for the rule |
| No sampler or owner named | "Sampler not named" or "owner not named", and ask | Never suggest a job title |
| No correction date set | "Date not set" | The person sets it; never propose one |

## Library facts

| Class | When | How to word it |
|---|---|---|
| No change recorded | `get_deltas` returns no change | "No change in the library's log from DATE (log began 12 October 2026) to LAST SWEEP; not a statement about the company" |
| Feed missing | A delta feed is not on the server | "Market Access changes are not available through this tool `[GAP]`" |
| Not returned in a rerun | A peer is missing from a later screen | "Not returned in this run (limit or ranking); not evidence of exit" |
| Runs not comparable | Different arguments | "Runs used different arguments; no change is inferred" |

## Requirement facts

| Situation | How to word it |
|---|---|
| A row states it | The rule plus the row id |
| Row marked [WF] | "Read through a summarizer; re-check before external use" |
| Row marked [INDUSTRY] | "Industry code, not law" |
| Draft or not implementable (FDA payor draft June 2026; SIUU pending OMB) | "Not in force as of the research read on 19 October 2026" |
| Change noted but content not read (HWG law of 26 June 2026) | "A change is recorded; its content is not in this skill's sources `[GAP]`" |

## Never

- Never treat a flag word as a breach, or its absence as compliance.
- Never infer a peer's intent, results or revenue from a change.
- Never fill a rule, a date or a pass rule from memory.
