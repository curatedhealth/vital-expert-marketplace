# Gap rules

A gap is information. Each reason for a gap leads to a different next step, so name the reason.

## Measures

No primary or peer-reviewed source defines renewal rate, churn, gross or net revenue retention, expansion, customer health, time to value or NPS as a renewal predictor for digital health (`customer-success-research.md`, "Not sourced"). Therefore:

| Situation | How to word it | Next step |
|---|---|---|
| Asked for "the standard" definition | "No source in this skill defines it; the figure will use your definition." | A1 |
| Asked for a benchmark or typical rate | "No benchmark is sourced; the figure is reported against your own rule only." | Ask for the rule |
| A definition the computation needs is missing | "Not computed: [definition] is yours to state `[GAP]`." The script refuses in the same way. | A1 |
| The person adopts a register starter rule | "Your rule (register starter rule SRn, adopted)." | None |

## The person's data

| Situation | How to word it |
|---|---|
| Value missing for an account in the base | "Value figures not computed: value missing for [accounts] `[GAP]`." Never compute on a partial base. |
| Status outside the person's lists | List the accounts; "counted nowhere until classified". |
| Open account past its renewal date | "Check the record: renewal date passed, status open." |
| Loss or refusal reason missing | "Reason not recorded `[GAP]`." |
| Offer outcome is a meeting or a verbal yes | Not signed unless the person's definition says so (SR15, SR22 if adopted). |
| No pass rule for a figure | Report the number; no verdict; ask for the rule. |
| No owner named | Use the owner or role the person names, in their words. Only if they named none, write "owner not named" and ask. Never suggest a job title. |
| No scores for B1 ranking | No ranking. Lay out the facts per repair and ask for scores. |

## Rule facts

| Class | How to word it |
|---|---|
| Sourced | The fact plus the row id. |
| [PAPER] row | Give the DOI from the row. |
| [WF] row | Say it rests on a page read through a summarizer. |
| [INDUSTRY] row | "a code, not law". |
| Not sourced | "Not in this skill's sources `[GAP]`." |

## Never

- Never fill a definition, threshold, owner, score or value from memory.
- Never read a high renewal rate as evidence that the product works, or a low one as evidence that it does not.
